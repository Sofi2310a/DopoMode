01 — Основи C++

Ласкаво просимо до C++! Якщо ти ніколи раніше не писав жодного рядка коду, ти потрапив саме туди, куди треба.

У цьому уроці ми пройдемо шлях від порожнього файлу до працюючої програми. По дорозі ти дізнаєшся, що таке C++, як він працює і як писати свої перші інструкції для комп’ютера.

Не хвилюйся, якщо щось спочатку здасться незнайомим. Кожен досвідчений програміст колись починав саме з того місця, де ти зараз.

Секрет вивчення програмування не в запам’ятовуванні команд. Головне — розуміти, що вони роблять, експериментувати з кодом і відкривати, як усе працює разом.

Готовий? Починаємо!

1. Що таке C++?

C++ — це потужна мова програмування, яку використовують для створення програмного забезпечення, відеоігор, застосунків і систем, що керують електронними пристроями.

Але що саме таке мова програмування?

Уяви, що ти хочеш, щоб комп’ютер щось обчислив, показав повідомлення або відреагував на натискання кнопки. Комп’ютер не здогадається, чого ти хочеш, поки ти не дасиш йому інструкції.

Саме тут на допомогу приходять мови програмування.

Мова програмування дозволяє писати інструкції, які кажуть комп’ютеру, які завдання виконувати.

Наприклад, за допомогою C++ можна створити програму, яка:

  • Показує привітальне повідомлення.
  • Розраховує вартість кількох товарів.
  • Просить користувача ввести інформацію.
  • Керує рухом персонажа у відеогрі.
  • Обмінюється даними з датчиками та електронними пристроями.

Ці приклади можуть здаватися дуже різними, але в них є одна спільна ідея: програміст пише інструкції, а комп’ютер їх виконує.

Де використовують C++?

Ти можеш здивуватися, у скількох різних галузях використовують C++.

Розробка ігор: C++ широко використовують для створення відеоігор та ігрових рушіїв. Він допомагає програмістам створювати системи, що відповідають за графіку, фізику, рух персонажів та інші вимогливі завдання.

Розробка програмного забезпечення: Багато настільних застосунків і професійних програмних інструментів використовують C++. Він особливо корисний, коли програмам потрібно ефективно обробляти інформацію.

Операційні системи: C++ можна використовувати для розробки компонентів операційних систем, системних утиліт і програм, що тісно взаємодіють з апаратним забезпеченням комп’ютера.

Робототехніка: Роботам потрібне програмне забезпечення, щоб обробляти дані з датчиків, керувати двигунами та ухвалювати рішення. C++ — одна з мов, які використовують для створення таких систем.

Вбудовані системи: C++ також використовують у пристроях, як-от розумна електроніка, промислові контролери та інші апаратні системи.

Чому програмісти обирають C++?

Одна з найбільших переваг C++ — продуктивність.

C++ дозволяє створювати ефективне програмне забезпечення та дає програмістам детальний контроль над тим, як програма використовує пам’ять та інші ресурси комп’ютера.

Проте цей контроль також накладає відповідальність. Програмістам потрібно розуміти, як працює їхній код, щоб уникати помилок.

Саме тому так важливо вивчати основи.

Пам’ятай: C++ — це більше, ніж мова для написання команд. Це інструмент, який перетворює твої ідеї на працююче програмне забезпечення.

2. Як працює C++?

Перш ніж писати першу програму, давай зрозуміємо, що відбувається з C++ кодом після того, як ми його створили.

Коли ти пишеш інструкції на C++, комп’ютер зазвичай не може виконати цей вихідний код безпосередньо.

Комп’ютери виконують машинні інструкції, тому наш C++ код потрібно перетворити на форму, яку комп’ютер зможе запустити.

Важливу роль у цьому процесі відіграє інструмент, який називається компілятором.

Що таке компілятор?

Компілятор — це програма, яка перевіряє вихідний код і перетворює його на форму нижчого рівня.

Для типового початкового застосунку на C++ процес виглядає так:

Вихідний код → Компіляція → Компонування → Виконуваний файл → Результат

Розгляньмо кожен крок.

Крок 1: Написання вихідного коду

Спочатку ми пишемо інструкції на C++.

Ці інструкції зберігаються у файлі з вихідним кодом, зазвичай із розширенням .cpp.

Наприклад:

main.cpp

Крок 2: Компіляція

Компілятор обробляє наш C++ код.

Він перевіряє, чи відповідає код правилам мови, і перетворює його на форму, з якої можна зібрати кінцеву програму.

Якщо компілятор знаходить певні помилки, як-от пропущена пунктуація або невідома назва змінної, він повідомляє про них.

Крок 3: Компонування

Після компіляції інструмент, який називається компонувальником (лінкером), поєднує скомпільований код з іншим кодом, потрібним програмі.

Це допомагає отримати готову виконувану програму.

Багато середовищ розробки виконують компіляцію та компонування разом, коли ти вибираєш команду Build.

Крок 4: Запуск програми

Коли програму успішно зібрано, її можна запустити.

Комп’ютер виконує її інструкції та робить те, що ми запрограмували.

Простий приклад

Уяви, що ти пишеш програму, яка виводить: Hello, World!

Спочатку ти пишеш інструкції на C++, збираєш програму, а потім запускаєш її.

Коли програма виконується, на екрані з’являється повідомлення. Це основна ідея того, як працюватимуть наші перші програми на C++.

Hello, World!

Чи може компілятор знайти кожну помилку?

Не зовсім.

Компілятор може виявити багато проблем у твоєму коді, але не завжди може визначити, чи робить програма те, що ти задумав.

Наприклад, якщо ти випадково додав два числа замість того, щоб їх перемножити, код може успішно скомпілюватися і все одно дати неправильну відповідь.

Саме тому програмісти не просто пишуть код. Вони також його тестують.

Пам’ятай: компіляція допомагає перетворити C++ код на працюючу програму, а тестування допомагає перевірити, чи програма поводиться правильно.

3. Інструменти для написання C++

Тепер, коли ти розумієш, як працюють програми на C++, подивімося, які інструменти потрібні для їх створення.

На щастя, для початку програмування не потрібне складне обладнання чи дороге програмне забезпечення. Тобі потрібне здебільшого місце для написання коду та спосіб його скомпілювати.

Редактор коду

Редактор коду — це застосунок, у якому програмісти пишуть і змінюють вихідний код. Уяви його як текстовий редактор, створений спеціально для програмування.

На відміну від звичайних текстових редакторів, редактори для програмування часто мають корисні функції, як-от підсвічування синтаксису, автоматичні відступи та підказки коду.

Компілятор

Компілятор обробляє твій вихідний код на C++ і перетворює його в рамках процесу збірки програми.

Без відповідного компілятора або середовища збірки ти, як правило, не зможеш перетворити свій C++ код на виконуваний застосунок.

IDE — інтегроване середовище розробки

IDE (Integrated Development Environment — інтегроване середовище розробки) поєднує кілька інструментів програмування в одному застосунку.

IDE може містити:

  • Редактор коду.
  • Інструменти для компіляції та збірки програм.
  • Налагоджувач (дебагер) для пошуку проблем.
  • Функції керування проєктами.
  • Підказки коду та інструменти навігації.

Використання IDE може зробити програмування зручнішим, адже більшість завдань можна виконувати в одному місці.

Популярні інструменти для C++

Visual Studio: Потужне середовище розробки, яке зазвичай використовують для програмування на C++ у Windows. Воно містить багато інструментів для створення, збірки, тестування та налагодження застосунків.

Visual Studio Code: Легкий і гнучкий редактор коду. Він підтримує розробку на C++ через розширення, а відповідний компілятор і засоби розробки потрібно налаштувати окремо.

Що таке файл .cpp?

Вихідний код C++ зазвичай зберігають у файлах із розширенням .cpp.

Наприклад:

main.cpp

Тут main — це ім’я файлу, а .cpp показує, що це файл із вихідним кодом C++.

У більшому проєкті можна створити багато різних файлів .cpp, але ми почнемо лише з одного.

Твій перший крок

Відкрий своє улюблене середовище розробки C++ і створи новий консольний проєкт або файл із вихідним кодом.

Назви файл: main.cpp

Ми використаємо цей файл, щоб написати нашу першу програму.

Пам’ятай: редактор коду допомагає писати інструкції, компілятор — перетворювати їх, а IDE може об’єднати всі ці інструменти.

Пишемо програму

Введи такий код у свій файл main.cpp: 

#include <iostream>

int main() {
    std::cout << "Hello, World!\n";
    return 0;
}

Тепер збери й запусти програму.

Якщо все налаштовано правильно, ти побачиш:

Вивід:

Hello, World!

Вітаємо! Ти створив повноцінну програму на C++.
