12 — Класи та об’єкти

Уяви, що ти створюєш гру з десятками персонажів. Кожен персонаж має ім’я, очки здоров’я та особливі здібності.

Чи не було б зручніше зберігати всю цю інформацію разом, замість того щоб керувати нею окремо?

Саме це дозволяють робити класи та об’єкти!

У цьому уроці ти познайомишся з основами об’єктно-орієнтованого програмування (ООП) та навчишся створювати власні класи в C++.

1. Що таке об’єктно-орієнтоване програмування?

Об’єктно-орієнтоване програмування (ООП) — це підхід до програмування, за якого код організовується навколо об’єктів.

Об’єкт може поєднувати дві важливі складові:

  • Дані — інформацію, наприклад ім’я гравця або кількість його здоров’я.
  • Поведінку — дії, наприклад атаку, лікування або відображення інформації.

ООП допомагає розробникам упорядковувати великі програми, повторно використовувати код і контролювати доступ до важливих даних.

Уяви клас як креслення, за яким можна створювати об’єкти. Подивімося, як це працює!

2. Що таке класи?

Клас — це власний тип даних, який визначає, яку інформацію міститиме об’єкт і які дії він зможе виконувати.

Створімо простий клас Student.

#include <iostream>
#include <string>

class Student {
public:
    std::string name;
    int age;

    void introduce() {
        std::cout << "Hi, I'm " << name << "!\n";
    }
};

Як це працює?

  • class Student — визначає клас із назвою Student.
  • name та age — поля класу, які зберігають інформацію.
  • introduce() — функція-член класу, яка виконує певну дію.
  • public: — дозволяє звертатися до цих членів класу ззовні.

Функцію, яка належить класу, називають функцією-членом. Її також часто називають методом.

Зверни увагу на крапку з комою після закривальної фігурної дужки. У C++ вона обов’язкова в кінці визначення класу.

3. Створення об’єктів

Об’єкт — це екземпляр класу.

Після визначення класу ми можемо створити стільки об’єктів, скільки потрібно.

#include <iostream>
#include <string>

class Student {
public:
    std::string name;
    int age;

    void introduce() {
        std::cout << "Hi, I'm " << name << "!\n";
    }
};

int main() {
    Student student1{};
    Student student2{};

    student1.name = "Alex";
    student1.age = 18;

    student2.name = "Emma";
    student2.age = 19;

    student1.introduce();
    student2.introduce();

    return 0;
}

Вивід:

Hi, I'm Alex!
Hi, I'm Emma!

Обидва об’єкти створені на основі одного класу, але кожен із них зберігає власну інформацію.

Ми використовуємо оператор крапки (.), щоб отримувати доступ до публічних полів і викликати функції-члени об’єкта.

Пам’ятай: один клас може створювати багато об’єктів, і кожен із них матиме власні дані.

4. Модифікатори доступу

Не всі частини об’єкта повинні бути доступними з будь-якого місця програми.

C++ надає специфікатори доступу, які визначають, звідки можна звертатися до членів класу.

Специфікатор доступу Значення
public Доступний ззовні класу
private Доступний усередині класу та його дружнім функціям і класам
protected Доступний усередині класу, його друзям і похідним класам

Розгляньмо приклад:

#include <iostream>

class BankAccount {
private:
    double balance = 1000.0;

public:
    void showBalance() const {
        std::cout << balance << "\n";
    }
};

int main() {
    BankAccount account;

    account.showBalance();

    return 0;
}

Вивід:

1000

Поле balance є приватним, тому ми не можемо звернутися до нього безпосередньо з функції main().

Однак публічна функція showBalance() може читати його значення.

Ключове слово const після дужок функції означає, що ця функція-член не може змінювати звичайні (не позначені mutable) поля об’єкта.

Пам’ятай: члени класу за замовчуванням є приватними. Використовуй public, щоб зробити необхідні операції доступними іншим частинам програми.

5. Інкапсуляція

Уяви банківський застосунок, у якому будь-хто може безпосередньо змінити баланс рахунку на довільне число.

Це був би невдалий підхід до проєктування!

Інкапсуляція — це принцип, за якого пов’язані дані та поведінка об’єднуються в одному класі, а доступ до даних і їх зміна контролюються.

Удоскональмо наш приклад банківського рахунку.

#include <iostream>

class BankAccount {
private:
    double balance = 0.0;

public:
    void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }

    double getBalance() const {
        return balance;
    }
};

int main() {
    BankAccount account;

    account.deposit(500);

    std::cout << account.getBalance() << "\n";

    return 0;
}

Вивід:

500

Поле balance є приватним, тому зовнішній код не може змінити його безпосередньо.

Натомість функція deposit() перевіряє, чи є сума додатною, перш ніж збільшити баланс.

Це простий приклад захисту внутрішнього стану об’єкта.

У реальному фінансовому програмному забезпеченні грошові значення потребують точного представлення та ретельної перевірки. Звичайний тип double зазвичай не підходить для точних фінансових розрахунків.

Пам’ятай: інкапсуляція допомагає захищати дані, надаючи контрольовані способи доступу до них та їх зміни.

6. Конструктори

А що, якщо ми хочемо, щоб кожен новий об’єкт студента відразу отримував ім’я та вік?

Для цього можна використати конструктор!

Конструктор — це спеціальна функція-член класу, яка використовується для ініціалізації об’єкта під час його створення.

Він має таку саму назву, як і клас, та не має типу значення, що повертається.

#include <iostream>
#include <string>

class Student {
private:
    std::string name;
    int age;

public:
    Student(std::string studentName, int studentAge)
        : name(studentName), age(studentAge) {
    }

    void introduce() const {
        std::cout << name << " is "
                  << age << " years old.\n";
    }
};

int main() {
    Student student("Alex", 18);

    student.introduce();

    return 0;
}

Вивід:

Alex is 18 years old.

Як це працює?

Коли ми створюємо об’єкт:

Student student("Alex", 18);

C++ викликає конструктор із переданими аргументами.

Ось ця частина:

: name(studentName), age(studentAge)

називається списком ініціалізації членів класу. Він ініціалізує поля об’єкта ще до виконання тіла конструктора.

Конструктори за замовчуванням

Конструктор за замовчуванням можна викликати без аргументів.

class Player {
public:
    int health;

    Player() : health(100) {
    }
};

Тепер створення об’єкта за допомогою:

Player player;

ініціалізує його поле health значенням 100.

Пам’ятай: конструктори допомагають забезпечити правильні початкові значення об’єктів.

7. Деструктори

Якщо конструктори готують об’єкти до використання, то що відбувається, коли ці об’єкти більше не потрібні?

Тут у пригоді стають деструктори.

Деструктор — це спеціальна функція-член класу, яка викликається, коли завершується час існування об’єкта.

Його назва починається із символу ~, після якого записується назва класу.

#include <iostream>

class Player {
public:
    Player() {
        std::cout << "Player created!\n";
    }

    ~Player() {
        std::cout << "Player destroyed!\n";
    }
};

int main() {
    Player player;

    return 0;
}

Вивід:

Player created!
Player destroyed!

Конструктор викликається під час створення об’єкта.

Деструктор викликається, коли завершується час існування локального об’єкта.

Деструктори особливо корисні для звільнення ресурсів, наприклад закриття файлів або звільнення динамічно виділеної пам’яті.

Для простих класів C++ зазвичай автоматично створює відповідний деструктор.

Пам’ятай: конструктори ініціалізують об’єкти, а деструктори допомагають звільняти ресурси під час їх знищення.

8. Вказівник this

Іноді параметр функції має таку саму назву, як і поле класу.

Як C++ розуміє, до якого саме значення ми звертаємося?

Для цього можна використати спеціальний вказівник this.

Усередині нестатичної функції-члена this вказує на об’єкт, для якого було викликано цю функцію.

#include <iostream>

class Player {
private:
    int health;

public:
    Player(int health) {
        this->health = health;
    }

    void showHealth() const {
        std::cout << health << "\n";
    }
};

int main() {
    Player player(100);

    player.showHealth();

    return 0;
}

Вивід:

100

У конструкторі:

  • this->health — звертається до поля об’єкта.
  • health — звертається до параметра конструктора.

Оператор -> дозволяє звертатися до члена об’єкта через вказівник.

Не обов’язково використовувати this у кожній функції-члені. Однак він корисний, коли назви збігаються або потрібно явно звернутися до поточного об’єкта.

Пам’ятай: вказівник this надає доступ до поточного об’єкта всередині нестатичної функції-члена.

9. Класи та структури: у чому різниця?

У попередньому уроці ти вже познайомився зі структурами struct.

І ось що цікаво: класи та структури в C++ дуже схожі!

Обидва типи можуть містити змінні, функції-члени, конструктори, деструктори та інші елементи.

Основні відмінності між ними стосуються доступу до членів за замовчуванням і типу успадкування за замовчуванням.

class struct
Члени за замовчуванням є приватними Члени за замовчуванням є публічними
Успадкування за замовчуванням є приватним Успадкування за замовчуванням є публічним
Часто використовується для об’єктів з інкапсуляцією Часто використовується для простих структур даних

Наприклад:

struct Point {
    int x;
    int y;
};

Поля структури Point за замовчуванням є публічними.

А якщо використати клас:

class Point {
    int x;
    int y;
};

Його поля за замовчуванням будуть приватними.

На практиці розробники часто використовують struct для простих контейнерів даних, а class — для об’єктів із контрольованим доступом до внутрішнього стану.

Пам’ятай: і class, і struct підтримують об’єктно-орієнтоване програмування. Обирай відповідний варіант залежно від того, як плануєш використовувати свій тип даних.
