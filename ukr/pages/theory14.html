14 — STL і файли

1. Що таке STL?

Стандартна бібліотека шаблонів (STL) — це набір готових інструментів для зберігання, організації та обробки даних у C++.

Замість того щоб самостійно створювати кожну структуру даних або алгоритм, ти можеш використовувати вже наявні компоненти стандартної бібліотеки C++.

STL містить три важливі складові:

  • Контейнери — зберігають набори даних.
  • Алгоритми — виконують такі операції, як сортування та пошук.
  • Ітератори — надають спосіб доступу до елементів контейнерів.

Використання STL дозволяє писати коротший код, спрощує його підтримку та допомагає ефективніше працювати з даними.

Головне: STL надає готові інструменти для повторного використання, завдяки яким програмістам не потрібно щоразу створювати все з нуля.

Практичне завдання

Наведи по одному прикладу з реального життя, у якому були б корисними контейнер, алгоритм та ітератор. Поясни, яку роль виконував би кожен із них.

2. Вектори

Вектор (vector) — це динамічний масив, який може автоматично збільшувати або зменшувати кількість елементів під час їх додавання чи видалення.

На відміну від звичайних масивів фіксованого розміру, для вектора не потрібно заздалегідь визначати кількість елементів.

Щоб використовувати вектори, підключи заголовковий файл <vector>.

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> numbers = {10, 20, 30};

    numbers.push_back(40);

    for (int number : numbers) {
        cout << number << " ";
    }

    return 0;
}

Вивід:

10 20 30 40

Основні операції з векторами

Операція Опис
push_back() Додає елемент у кінець вектора
pop_back() Видаляє останній елемент
size() Повертає кількість елементів
empty() Перевіряє, чи вектор порожній
at() Надає доступ до елемента з перевіркою меж
clear() Видаляє всі елементи

Наприклад:

vector<int> scores = {80, 90, 100};

cout << scores.at(0) << endl;
cout << scores.size();

Вивід:

80
3

Пам’ятай: використовуй vector, коли потрібен набір елементів, розмір якого може змінюватися.

Практичне завдання

Створи вектор із трьома оцінками. Додай ще одну за допомогою push_back(), видали останній елемент за допомогою pop_back(), а потім виведи решту значень і розмір вектора.

3. Інші контейнери STL

C++ пропонує різні контейнери для різних завдань.

array — колекція фіксованого розміру

Контейнер std::array зберігає фіксовану кількість елементів.

#include <array>

array<int, 3> numbers = {10, 20, 30};

На відміну від традиційного масиву в стилі C, std::array надає корисні функції, наприклад .size() і .at().

map — пари «ключ — значення»

Мапа (map) зберігає інформацію у вигляді пар ключів і відповідних їм значень.

Наприклад, можна зберігати імена студентів та їхні оцінки.

#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<string, int> scores;

    scores["Alex"] = 90;
    scores["Emma"] = 95;

    cout << scores["Emma"];

    return 0;
}

Вивід:

95

Кожен ключ у map є унікальним, а елементи впорядковуються за ключами.

set — унікальні значення

Множина (set) зберігає унікальні значення у відсортованому порядку.

#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> numbers = {5, 2, 5, 1};

    for (int number : numbers) {
        cout << number << " ";
    }

    return 0;
}

Вивід:

1 2 5

Значення 5 повторюється у вихідному наборі, але множина зберігає його лише один раз.

Головне: обирай контейнер залежно від того, як саме потрібно організовувати дані та отримувати до них доступ.

Практичне завдання

Створи map, який зберігатиме оцінки двох студентів, і set зі значеннями {4, 2, 4, 1}. Виведи оцінку одного студента та всі унікальні елементи множини.

4. Алгоритми STL

Алгоритми — це готові функції, які виконують типові операції над наборами даних.

Заголовковий файл <algorithm> містить багато корисних функцій.

Ось найпоширеніші з них:

Алгоритм Опис
sort() Сортує елементи
find() Шукає задане значення
reverse() Змінює порядок елементів на зворотний
count() Підраховує кількість входжень значення
max_element() Знаходить найбільший елемент
min_element() Знаходить найменший елемент

Сортування вектора

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> numbers = {5, 2, 8, 1, 3};

    sort(numbers.begin(), numbers.end());

    for (int number : numbers) {
        cout << number << " ";
    }

    return 0;
}

Вивід:

1 2 3 5 8

Функція sort() впорядковує числа за зростанням.

Пошук елемента

vector<int> numbers = {10, 20, 30};

auto result = find(numbers.begin(), numbers.end(), 20);

if (result != numbers.end()) {
    cout << "Number found!";
}

Вивід:

Number found!

Функція find() повертає ітератор на знайдений елемент. Якщо значення не знайдено, вона повертає ітератор кінця діапазону.

Пам’ятай: алгоритми STL дозволяють виконувати типові операції без необхідності самостійно писати складні цикли.

Практичне завдання

Створи вектор зі значеннями {9, 3, 7, 3, 1}. Відсортуй його, а потім використай count(), щоб визначити, скільки разів зустрічається число 3.

5. Ітератори

Ітератор — це об’єкт, який використовується для доступу до елементів контейнера.

Ітератори працюють подібно до вказівників і дозволяють послідовно переміщуватися елементами колекції.

Наприклад:

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> numbers = {10, 20, 30};

    for (auto it = numbers.begin(); it != numbers.end(); ++it) {
        cout << *it << " ";
    }

    return 0;
}

Вивід:

10 20 30

У цьому прикладі:

  • begin() — повертає ітератор на перший елемент.
  • end() — повертає ітератор, що позначає позицію після останнього елемента.
  • ++it — переміщує ітератор до наступного елемента.
  • *it — надає доступ до поточного елемента.

Важливо: Ітератор, який повертає end(), не можна розіменовувати.

Ітератори особливо корисні під час роботи з алгоритмами STL.

Головне: ітератори надають спільний спосіб доступу до елементів різних контейнерів.

Практичне завдання

Виведи кожен елемент вектора за допомогою begin(), end(), ++it і *it. Не розіменовуй ітератор end().

6. Що таке робота з файлами?

Зазвичай інформація, яка зберігається у змінних, зникає після завершення програми.

Робота з файлами дозволяє програмам зберігати інформацію та зчитувати її під час наступних запусків.

Наприклад, програма може зберігати у файлі оцінки студентів, налаштування користувача або прогрес у грі.

Для роботи з файлами C++ надає заголовковий файл <fstream>.

Існують три поширені типи файлових потоків:

Тип Призначення
ofstream Записує дані у файл
ifstream Зчитує дані з файлу
fstream Підтримує читання та запис

Головне: файли дозволяють програмам зберігати інформацію навіть після завершення роботи.

Шляхи до файлів: відносні та абсолютні

Відносний шлях, наприклад "notes.txt", визначається відносно поточного робочого каталогу програми, а не обов’язково папки, у якій розташований main.cpp або виконуваний файл.

Абсолютний шлях явно вказує розташування файлу, але його синтаксис залежить від операційної системи.

Перевірити поточний робочий каталог можна за допомогою std::filesystem::current_path(). Для цього потрібно підключити <filesystem> і використовувати C++17 або новіший стандарт.

Завжди переконуйся, що потрібний каталог існує, а програма має дозвіл на доступ до нього.

#include <iostream>
#include <filesystem>

int main() {
    std::cout << std::filesystem::current_path() << "\n";
}

Перевірка стану файлових потоків

Файловий потік зберігає інформацію про те, чи успішно виконуються операції.

Функція is_open() показує, чи відкритий файл. Перевірка if (file) дозволяє визначити, чи перебуває потік у стані, придатному для подальших операцій.

Функція fail() виявляє помилку операції, bad() повідомляє про серйозну помилку введення-виведення, а eof() показує, що було досягнуто кінця файлу.

Під час читання за допомогою while (getline(file, line)) цикл зазвичай завершується, коли досягнуто кінця файлу. Якщо потрібно відрізнити нормальне завершення читання від серйозної помилки, перевір bad().

Практичне завдання

Поясни, який тип файлового потоку ти використаєш для запису у grades.txt, читання з grades.txt, а також для одночасної підтримки читання та запису у settings.txt.

7. Запис даних у файл

Щоб записати інформацію у файл, використовують ofstream.

Наприклад:

#include <iostream>
#include <fstream>
using namespace std;

int main() {
    ofstream file("notes.txt");

    if (file.is_open()) {
        file << "Hello, C++!" << endl;
        file << "Learning file handling.";

        file.close();
        cout << "File saved!";
    } else {
        cout << "Cannot open file!";
    }

    return 0;
}

Вивід у консоль:

File saved!

Вміст файлу notes.txt:

Hello, C++!
Learning file handling.

Як це працює?

  • ofstream file("notes.txt") — відкриває файл для запису.
  • is_open() — перевіряє, чи вдалося відкрити файл.
  • file << — записує інформацію у файл.
  • close() — закриває файл.

За замовчуванням відкриття наявного файлу через ofstream у такий спосіб замінює його попередній вміст.

Пам’ятай: використовуй ofstream, щоб зберігати інформацію у файлах.

Перевірка успішності запису

#include <fstream>
#include <iostream>

int main() {
    std::ofstream file("notes.txt");
    if (!file.is_open()) {
        std::cerr << "Cannot open file!\n";
        return 1;
    }

    file << "Hello, C++!\n";
    file.close();

    if (!file) {
        std::cerr << "Could not finish writing.\n";
        return 1;
    }

    std::cout << "File saved!\n";
}

Перевіряй не лише те, чи вдалося відкрити файл, а й чи успішно завершилися запис і закриття.

Під час закриття потоку можуть виявитися помилки буферизованого запису, які не були помітні раніше.

Практичне завдання

Запиши три окремі рядки у файл scores.txt. Перевір, чи відкрився файл і чи успішно завершився запис.

8. Читання даних із файлу

Щоб зчитати інформацію з наявного файлу, використовують ifstream.

Наприклад:

#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main() {
    ifstream file("notes.txt");
    string line;

    if (file.is_open()) {
        while (getline(file, line)) {
            cout << line << endl;
        }

        file.close();
    } else {
        cout << "Cannot open file!";
    }

    return 0;
}

Якщо notes.txt містить текст із попереднього прикладу, результат буде таким:

Hello, C++!
Learning file handling.

Функція getline() зчитує один повний рядок за раз.

Цикл while продовжується, доки є рядки для читання.

Головне: використовуй ifstream, щоб отримувати інформацію, збережену у файлах.

Відносна назва файлу визначається з урахуванням поточного робочого каталогу. Якщо файл не знайдено, перевір цей каталог і правильність назви файлу.

Після завершення циклу читання file.bad() може допомогти виявити серйозні помилки введення. Звичайне досягнення кінця файлу є очікуваним і не обов’язково означає проблему.

Практичне завдання

Прочитай файл scores.txt рядок за рядком за допомогою getline(). Якщо файл не вдається відкрити, виведи зрозуміле повідомлення про помилку.

9. Додавання даних у кінець файлу

Іноді потрібно додати нову інформацію, не видаляючи те, що вже зберігається у файлі.

Це називається дописуванням у файл.

Щоб додати дані в кінець файлу, використовуй ios::app.

#include <iostream>
#include <fstream>
using namespace std;

int main() {
    ofstream file("notes.txt", ios::app);

    if (file.is_open()) {
        file << "\nNew information added.";
        file.close();

        cout << "Text added!";
    } else {
        cout << "Cannot open file!";
    }

    return 0;
}

Вивід:

Text added!

Якщо файл уже містить:

Hello, C++!

Після виконання програми його вміст стане таким:

Hello, C++!
New information added.

Пам’ятай: використовуй ios::app, коли потрібно додати дані в кінець файлу, не замінюючи його попередній вміст.

Практичне завдання

Додай один новий рядок у файл scores.txt за допомогою ios::app. Потім відкрий файл ще раз і переконайся, що попередні рядки залишилися на місці.

10. Типові помилки під час роботи з файлами

Під час роботи з файлами важливо дотримуватися кількох правил.

1. Припущення, що файл завжди існує

Файл може бути відсутнім або недоступним. Завжди перевіряй, чи вдалося його відкрити.

2. Використання неправильного шляху до файлу

Відносний шлях, наприклад "notes.txt", зазвичай визначається відносно поточного робочого каталогу програми, який може відрізнятися від папки з вихідним кодом.

3. Випадкове перезаписування даних

Відкриття файлу через ofstream зазвичай замінює його попередній вміст, якщо не використано відповідний режим, наприклад ios::app.

4. Ігнорування помилок запису

Успішне відкриття файлу не гарантує, що кожна операція запису завершиться успішно. Для важливих даних перевіряй стан потоку після запису.

5. Незакриття файлів

Файлові потоки автоматично закриваються під час знищення їхніх об’єктів. Проте явний виклик close() може бути корисним, коли потрібно завершити роботу з файлом до закінчення програми.

Головне: завжди уважно виконуй файлові операції, щоб уникнути втрати важливої інформації.

Практичне завдання

Запусти свою програму для роботи з файлами з двох різних робочих каталогів. Визнач, який шлях до notes.txt використовується в кожному випадку, а потім перевір стан потоку після запису.
