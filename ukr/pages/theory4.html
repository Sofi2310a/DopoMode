04 — Умови

Що, якби твоя програма могла ухвалювати рішення?

Уяви гру, яка перевіряє, чи достатньо в гравця балів, щоб розблокувати новий рівень, або застосунок, що перевіряє вік користувача.

У C++ умови дозволяють програмам обирати різні дії залежно від того, істинне щось чи хибне.

Дізнаймося, як вони працюють!

1. Інструкція if

Інструкція if виконує блок коду лише тоді, коли умова істинна.

Наприклад, перевіримо, чи достатньо людині років, щоб потрапити на захід.

#include <iostream>

int main() {
    int age = 20;

    if (age >= 18) {
        std::cout << "Access granted!\n";
    }

    return 0;
}

Вивід:

Access granted!

Програма перевіряє, чи вік не менший за 18.

Якщо умова істинна, з’являється повідомлення. В іншому випадку код у фігурних дужках пропускається.

Пам’ятай: if виконує код лише тоді, коли його умова істинна.

2. Інструкція if-else

Іноді нам потрібно обрати одну з двох можливих дій.

Саме тут з’являється else.

int temperature = 15;

if (temperature >= 20) {
    std::cout << "It is warm!\n";
} else {
    std::cout << "It is cold!\n";
}

Вивід:

It is cold!

Оскільки температура нижча за 20, програма виконує блок else.

Пам’ятай: if обробляє випадок, коли умова істинна, а else — альтернативний.

3. Інструкція else-if

А що, якщо можливих результатів більше двох?

Ми можемо використати else if, щоб перевірити додаткові умови.

int score = 85;

if (score >= 90) {
    std::cout << "Excellent!\n";
} else if (score >= 70) {
    std::cout << "Good!\n";
} else if (score >= 50) {
    std::cout << "Passed!\n";
} else {
    std::cout << "Failed!\n";
}

Вивід:

Good!

C++ перевіряє умови зверху вниз.

Щойно він знаходить істинну умову, він виконує відповідний блок і пропускає решту гілок.

Пам’ятай: else if допомагає обрати між кількома можливими результатами.

4. Поєднання умов

Іноді однієї умови недостатньо.

Уяви концерт, на який відвідувачам має бути щонайменше 18 років і потрібен квиток.

Ми можемо поєднувати умови за допомогою логічних операторів.

ОператорІм’яЗначення
&&І (AND)Обидві умови мають бути істинними
||АБО (OR)Принаймні одна умова має бути істинною
!НЕ (NOT)Змінює логічне значення на протилежне

Спробуймо приклад:

int age = 20;
bool hasTicket = true;

if (age >= 18 && hasTicket) {
    std::cout << "Access granted!\n";
} else {
    std::cout << "Access denied!\n";
}

Вивід:

Access granted!

Обидві умови істинні, тому доступ надано.

Ці оператори дозволяють створювати точніші правила для твоїх програм.

5. Інструкція switch

Коли потрібно порівняти одне значення з кількома фіксованими варіантами, switch може бути зручною альтернативою кільком інструкціям else if.

Наприклад, виведімо день тижня.

int day = 2;

switch (day) {
    case 1:
        std::cout << "Monday\n";
        break;
    case 2:
        std::cout << "Tuesday\n";
        break;
    case 3:
        std::cout << "Wednesday\n";
        break;
    default:
        std::cout << "Unknown day\n";
}

Вивід:

Tuesday

Ось як це працює:

  • switch перевіряє значення.
  • case визначає можливий збіг.
  • break виходить із switch.
  • default обробляє значення, які не збігаються з жодним case.

Без break виконання може перейти до наступного case.

Важливо: звичайний C++ switch працює з цілими числами, символами та значеннями перелічень, але не безпосередньо з std::string.

6. Тернарний оператор

C++ пропонує коротший спосіб вибору між двома значеннями за допомогою тернарного оператора ?:.

Його структура: умова ? valueIfTrue : valueIfFalse

Подивімося на приклад:

int age = 20;

std::string result = (age >= 18) ? "Adult" : "Minor";

std::cout << result << "\n";

Вивід:

Adult

Якщо умова істинна, обирається перше значення. В іншому випадку обирається друге.

Це корисно для простих рішень, але для складнішої логіки зазвичай зрозуміліший if-else.

7. Вкладені умови

Іноді одне рішення залежить від іншого.

Наприклад, відвідувач має бути дорослим, перш ніж ми перевіримо, чи є в нього посвідчення особи.

int age = 20;
bool hasID = true;

if (age >= 18) {
    if (hasID) {
        std::cout << "Entry allowed!\n";
    } else {
        std::cout << "ID required!\n";
    }
} else {
    std::cout << "You are too young!\n";
}

Вивід:

Entry allowed!

Спочатку програма перевіряє вік. Якщо відвідувач достатньо дорослий, вона перевіряє наявність посвідчення.

Це називається вкладеною умовою.

Вкладені умови корисні, але занадто багато рівнів може ускладнити читання коду.
