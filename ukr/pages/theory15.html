15 — Final Project

Congratulations! You've reached the final project of your C++ course!

You've learned how to use variables, conditions, loops, functions, arrays, pointers, classes, containers, and files.

Now it's time to bring everything together and create a real application.

Your challenge is to build a Student Management System — a console application that allows users to add, view, search, update, and delete student records.

This project will help you understand how different C++ concepts work together in a complete program.

1. Project Overview

Intermediate

Final Project

Project Name: Student Management System

Your application will manage student information through a simple text-based menu.

Each student should have four properties:

  • ID — a unique number identifying the student.
  • Name — the student's full name.
  • Age — the student's age.
  • Grade — the student's average score.

The application must also save student records to a file so they remain available after the program closes.

2. Step 01 — Create the Student Class

Let's start by defining what a student looks like in our program.

We'll use a class to keep related information and behavior together.

#include <iostream>
#include <string>
#include <vector>
#include <fstream>
#include <limits>

class Student {
public:
    int id;
    std::string name;
    int age;
    double grade;

    Student(int i, std::string n, int a, double g)
        : id(i), name(n), age(a), grade(g) {
    }

    void display() const {
        std::cout << "ID: " << id << "\n";
        std::cout << "Name: " << name << "\n";
        std::cout << "Age: " << age << "\n";
        std::cout << "Grade: " << grade << "\n";
    }
};

How Does It Work?

The Student class contains four data members and a function called display().

The constructor initializes a student with the information we provide.

For example:

Student student1(1, "Alex", 18, 95.5);

student1.display();

Output:

ID: 1
Name: Alex
Age: 18
Grade: 95.5

For simplicity, our class uses public data members. In larger applications, private members and controlled access can help protect data.

Remember: Classes allow us to organize related information and behavior into reusable objects.

3. Step 02 — Store Students in a Vector

A school can have many students, and we don't know exactly how many records our application will need.

That's why we'll use std::vector.

Unlike regular arrays, vectors can grow when new elements are added.

std::vector<Student> students;

To add a student:

students.emplace_back(1, "Alex", 18, 95.5);

Now let's create a function that displays all students.

void viewStudents(const std::vector<Student>& students) {
    if (students.empty()) {
        std::cout << "No students found.\n";
        return;
    }

    for (const Student& student : students) {
        student.display();
        std::cout << "----------\n";
    }
}

The range-based for loop visits every student in the vector.

We use const Student& to access each student without making an unnecessary copy.

Your Task

  2. Checks that the ID isn't already used.
  3. Validates the entered information.
  4. Adds the new student to the vector.

Important: Every student must have a unique ID.

4. Step 03 — Search for Students

Now let's add a search feature.

Imagine having 100 students in your system. Finding one manually would take too much time.

Instead, we'll create a function that searches by student ID.

Student* findStudent(std::vector<Student>& students, int id) {
    for (Student& student : students) {
        if (student.id == id) {
            return &student;
        }
    }

    return nullptr;
}

How Does It Work?

The function checks each student until it finds a matching ID.

If a match is found, it returns a pointer to that student.

Otherwise, it returns nullptr.

Here's how to use it:

Student* result = findStudent(students, 1);

if (result != nullptr) {
    result->display();
} else {
    std::cout << "Student not found.\n";
}

Important: Pointers to vector elements can become invalid when the vector is modified. Use the result immediately and don't keep it after operations that may invalidate it.

Your Task

Add a menu option that asks for a student ID and displays the matching student's information.

5. Step 04 — Update and Delete Students

Our application can now store and search for students.

Next, let's allow users to edit or remove records.

Updating a Student

Create an updateStudent() function that:

  1. Asks for the student's ID.
  2. Finds the matching student.
  3. Displays a message if no student is found.
  4. Asks for the new name, age, and grade.
  5. Updates the existing record after validating the new information.

You can reuse the findStudent() function to locate the student.

Deleting a Student

To remove a student, we can use the vector's erase() function.

void deleteStudent(std::vector<Student>& students, int id) {
    for (auto it = students.begin();
         it != students.end(); ++it) {

        if (it->id == id) {
            students.erase(it);
            std::cout << "Student deleted!\n";
            return;
        }
    }

    std::cout << "Student not found.\n";
}

The function searches for a matching ID and removes that record.

After calling erase(), the removed element and subsequent elements may no longer be accessible through previously saved iterators or pointers.

What Is CRUD?

These four operations have a common name in software development:

Operation Meaning
Create Add a new record
Read View or search for a record
Update Modify an existing record
Delete Remove a record

Together, they're known as CRUD.

You'll encounter these operations in databases, websites, and many real applications.

6. Step 05 — Save Students to a File

There's one important problem with our application so far.

When the program closes, the student records stored in memory disappear.

To keep them, we need file handling.

Let's save our student data to a text file.

void saveStudents(const std::vector<Student>& students) {
    std::ofstream file("students.txt");

    if (!file.is_open()) {
        std::cout << "Cannot open file!\n";
        return;
    }

    for (const Student& student : students) {
        file << student.id << "\n";
        file << student.name << "\n";
        file << student.age << "\n";
        file << student.grade << "\n";
    }

    file.close();

    if (file) {
        std::cout << "Students saved!\n";
    } else {
        std::cout << "Error saving students!\n";
    }
}

Example File Content

1
Alex
18
95.5
2
Emma
19
92

Each student occupies four lines in the file.

The first line contains the ID, followed by the name, age, and grade.

Opening an existing file with std::ofstream in this way normally replaces its previous contents, so the application should report saving errors clearly.

Your Task

Create a function named loadStudents() that:

  1. Opens students.txt when the program starts.
  2. Reads four fields for each student.
  3. Creates a Student object from each valid record.
  4. Adds the student to the vector.
  5. Handles missing files, incomplete records, invalid values, and duplicate IDs.

For this project, keep names on one line without embedded newline characters. Use a consistent numeric format and locale when saving and loading grades.

Remember: Saving data allows your application to keep information between sessions.

7. Step 06 — Create the Main Menu

Now it's time to connect everything into one application.

We'll use a do-while loop to keep the menu running and a switch statement to handle the user's choices.

The following example is a starting template. It assumes the Student class and the functions shown earlier have already been defined.

int main() {
    std::vector<Student> students;
    int choice = -1;

    do {
        std::cout << "\n===== STUDENT MANAGEMENT =====\n";
        std::cout << "1. Add Student\n";
        std::cout << "2. View Students\n";
        std::cout << "3. Search Student\n";
        std::cout << "4. Update Student\n";
        std::cout << "5. Delete Student\n";
        std::cout << "6. Save Students\n";
        std::cout << "0. Exit\n";
        std::cout << "Choose an option: ";

        if (!(std::cin >> choice)) {
            if (std::cin.eof()) {
                std::cout << "\nInput ended.\n";
                break;
            }

            std::cout << "Invalid input!\n";
            std::cin.clear();
            std::cin.ignore(
                std::numeric_limits<std::streamsize>::max(),
                '\n'
            );
            continue;
        }

        std::cin.ignore(
            std::numeric_limits<std::streamsize>::max(),
            '\n'
        );

        switch (choice) {
            case 1:
                std::cout << "Add Student selected\n";
                break;

            case 2:
                viewStudents(students);
                break;

            case 3:
                std::cout << "Search Student selected\n";
                break;

            case 4:
                std::cout << "Update Student selected\n";
                break;

            case 5:
                std::cout << "Delete Student selected\n";
                break;

            case 6:
                saveStudents(students);
                break;

            case 0:
                std::cout << "Goodbye!\n";
                break;

            default:
                std::cout << "Invalid option!\n";
        }

    } while (choice != 0);

    return 0;
}
