09 — Вказівники

Кожна змінна в програмі має своє місце в пам’яті. А що, якби ти міг звертатися до цього місця безпосередньо?

У C++ вказівники — це змінні, які зберігають адреси пам’яті замість звичайних значень.

Вони є однією з найважливіших концепцій C++ і допомагають зрозуміти, як за лаштунками працюють пам’ять, масиви, функції та динамічне виділення пам’яті.

Розберімо їх крок за кроком!

1. Що таке вказівники?

Вказівник — це змінна, яка зберігає адресу пам’яті іншої змінної або об’єкта.

Замість того щоб безпосередньо містити число, як-от 42, вказівник містить адресу, за якою 42 зберігається в пам’яті.

Чим корисні вказівники?

  • Робота з пам’яттю — доступ до об’єктів за їхніми адресами.
  • Зміна змінних усередині функцій — дозволяє функції безпосередньо оновлювати наявну змінну.
  • Динамічні структури даних — створення зв’язних списків, дерев і графів.
  • Продуктивність — доступ до великих об’єктів без зайвого копіювання.

Пам’ятай: звичайна змінна зберігає значення, а вказівник — адресу пам’яті.

2. Адреси пам’яті

Коли ти створюєш змінну, C++ зберігає її десь у пам’яті комп’ютера.

Дізнатися адресу пам’яті змінної можна за допомогою оператора взяття адреси (&).

#include <iostream>

int main() {
    int number = 42;

    std::cout << "Value: " << number << "\n";
    std::cout << "Address: " << &number << "\n";

    return 0;
}

Приклад виводу:

Value: 42
Address: 0x7ffee4b2c8ac

Точна адреса виглядає як шістнадцяткове число й може змінюватися під час кожного запуску програми.

Пам’ятай: &variable дає адресу пам’яті, за якою зберігається ця змінна.

3. Створення вказівника

Щоб створити вказівник, запиши тип даних об’єкта, на який він вказує, а потім зірочку (*).

int number = 42;
int* ptr = &number;

Тут:

  • int* означає «вказівник на int».
  • ptr — це ім’я вказівника.
  • &number отримує адресу number і зберігає її в ptr.
#include <iostream>

int main() {
    int number = 42;
    int* ptr = &number;

    std::cout << "Address of number: " << &number << "\n";
    std::cout << "Value stored in ptr: " << ptr << "\n";

    return 0;
}

Приклад виводу:

Address of number: 0x7ffee4b2c8ac
Value stored in ptr: 0x7ffee4b2c8ac

Обидва рядки виводять однакову адресу, тому що ptr вказує на number.

Пам’ятай: * використовують для оголошення вказівника, а & отримує адресу об’єкта.

4. Розіменування вказівників

Коли вказівник зберігає адресу, ти можеш отримати доступ до значення за цією адресою за допомогою оператора розіменування (*).

Розіменування вказівника означає доступ до об’єкта, на який він вказує.

#include <iostream>

int main() {
    int number = 42;
    int* ptr = &number;

    std::cout << "Address: " << ptr << "\n";
    std::cout << "Value: " << *ptr << "\n";

    return 0;
}

Вивід:

Address: 0x7ffee4b2c8ac
Value: 42

Зміна значення через вказівник

Ти також можеш змінити вихідну змінну через вказівник.

int number = 42;
int* ptr = &number;

*ptr = 100;

std::cout << "Updated number: " << number << "\n";

Вивід:

Updated number: 100

Зміна *ptr безпосередньо оновлює number, тому що обидва посилаються на ту саму ділянку пам’яті.

Пам’ятай: ptr дає адресу, а *ptr дає доступ до значення за цією адресою.

5. Нульові вказівники

Іноді вказівник поки що не повинен ні на що вказувати.

У сучасному C++ порожній вказівник ініціалізують за допомогою nullptr.

int* ptr = nullptr;

Нульовий вказівник не вказує на коректний об’єкт. Його завжди слід перевіряти, перш ніж намагатися через нього до чогось звернутися.

#include <iostream>

int main() {
    int* ptr = nullptr;

    if (ptr != nullptr) {
        std::cout << *ptr << "\n";
    } else {
        std::cout << "Pointer is null!\n";
    }

    return 0;
}

Вивід:

Pointer is null!

Ніколи не розіменовуй нульовий вказівник — це спричиняє невизначену поведінку і зазвичай аварійно завершує програму.

Пам’ятай: ініціалізуй невикористані вказівники значенням nullptr і перевіряй перед розіменуванням.

6. Вказівники та функції

За замовчуванням C++ передає аргументи за значенням, тобто функція отримує копію змінної.

За допомогою вказівників функція може отримати адресу змінної та змінити вихідну змінну.

#include <iostream>

void doubleValue(int* value) {
    *value = (*value) * 2;
}

int main() {
    int number = 10;
    doubleValue(&number);

    std::cout << "Number: " << number << "\n";

    return 0;
}

Вивід:

Number: 20

Як це працює?

  • &number передає адресу number у функцію.
  • int* value отримує цю адресу.
  • *value змінює вихідну змінну в main().

Пам’ятай: передача вказівника дозволяє функції змінювати вихідний об’єкт за його адресою.

7. Вказівники та масиви

У багатьох виразах ім’я масиву перетворюється на вказівник на його перший елемент.

#include <iostream>

int main() {
    int numbers[3] = {10, 20, 30};
    int* ptr = numbers;

    std::cout << *ptr << "\n";
    std::cout << *(ptr + 1) << "\n";
    std::cout << *(ptr + 2) << "\n";

    return 0;
}

Вивід:

10
20
30

Що тут відбувається?

  • ptr вказує на numbers[0].
  • ptr + 1 переходить до наступного int у пам’яті (numbers[1]).
  • ptr + 2 переходить до numbers[2].

Зауваж, що масиви та вказівники не тотожні — наприклад, sizeof(numbers) повертає розмір усього масиву, а sizeof(ptr) — розмір самого вказівника, — хоча вони тісно пов’язані!

Пам’ятай: арифметика вказівників може переміщатися елементами одного масиву, але розіменування поза межами масиву некоректне.

8. Динамічна пам’ять

Зазвичай змінні створюються автоматично й знищуються, коли закінчується їхня область видимості.

C++ також дозволяє виділяти пам’ять динамічно під час виконання програми за допомогою new та звільняти її за допомогою delete.

#include <iostream>

int main() {
    int* ptr = new int;
    *ptr = 25;

    std::cout << "Dynamic value: " << *ptr << "\n";

    delete ptr;
    ptr = nullptr;

    return 0;
}

Вивід:

Dynamic value: 25

Як це працює?

  • new int виділяє в купі (heap) пам’ять для одного int і повертає його адресу.
  • *ptr = 25 зберігає значення в цій пам’яті.
  • delete ptr знищує об’єкт і звільняє пам’ять, коли робота з нею завершена.
  • ptr = nullptr дозволяє не залишати після себе висячий вказівник.

Що таке витік пам’яті?

Якщо динамічно виділену пам’ять ніколи не звільнено за допомогою delete, вона залишається зарезервованою до завершення програми. Це називається витоком пам’яті.

У сучасному C++ часто віддають перевагу розумним вказівникам, як-от std::unique_ptr, тому що вони автоматично очищають пам’ять.

Пам’ятай: кожному «сирому» new має відповідати delete (а new[] — delete[]).

9. Типові помилки зі вказівниками

Вказівники потужні, тому навіть дрібні помилки можуть спричинити серйозні баги.

Неініціалізовані вказівники

Ніколи не використовуй вказівник, перш ніж присвоїти йому коректну адресу або nullptr.

int* ptr; // Не ініціалізовано!
// *ptr = 10; // Невизначена поведінка!

Цей локальний вказівник має невизначене значення. Його розіменування до ініціалізації може призвести до невизначеної поведінки.

Висячі вказівники

Висячий вказівник посилається на об’єкт, якого більше не існує, наприклад на пам’ять, яку вже звільнено.

int* ptr = new int(5);
delete ptr;
// *ptr = 10; // Не розіменовуй після delete!
ptr = nullptr;

Після виклику delete не використовуй стару адресу знову; можна скинути вказівник на nullptr.

Доступ до недійсної пам’яті

Спроба звернутися до пам’яті поза межами коректних об’єктів або масивів може аварійно завершити програму або пошкодити дані.

Наприклад:

int numbers[3] = {10, 20, 30};
int* ptr = numbers;
// *(ptr + 5) = 99; // Вихід за межі!

Пам’ятай: правильно ініціалізуй вказівники, уникай висячих вказівників і ніколи не розіменовуй недійсні адреси.
