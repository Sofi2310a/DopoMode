03 — Operators

Now that you know how to store information in variables, it's time to learn what you can do with it!

In this lesson, you'll discover how C++ performs calculations, compares values, and works with conditions.

These operations are essential for everything from simple calculators to interactive games.

1. What Are Operators?

Operators are symbols that tell C++ to perform an action on values or variables.

For example, the + operator adds two numbers:

#include <iostream>

int main() {
    int result = 10 + 5;
    std::cout << result << "\n";

    return 0;
}

Output:

15

Here, 10 and 5 are the values we're working with, while + is the operator.

C++ provides different operators for calculations, comparisons, updating variables, and combining conditions.

Let's explore the most useful ones.

2. Arithmetic Operators

Arithmetic operators allow us to perform mathematical calculations.

OperatorOperationExampleResult
+Addition5 + 38
-Subtraction5 - 32
*Multiplication5 * 315
/Division10 / 25
%Remainder10 % 31

Let's try them in a program:

#include <iostream>

int main() {
    int a = 10;
    int b = 3;

    std::cout << "Sum: " << a + b << "\n";
    std::cout << "Division: " << a / b << "\n";
    std::cout << "Remainder: " << a % b << "\n";

    return 0;
}

Output:

Sum: 13
Division: 3
Remainder: 1

Integer Division

Notice something interesting: 10 / 3 gives us 3, not 3.33.

That's because both numbers are integers. When dividing two integers, C++ discards the fractional part of the result. To get a decimal result, use floating-point numbers:

double result = 10.0 / 3.0;
std::cout << result << "\n";

Output (with default formatting):

3.33333

What Does % Do?

The % operator gives us the remainder of integer division.

For example:

std::cout << 10 % 3;

Output:

1

Why? Because 3 fits into 10 three times, leaving a remainder of 1.

This operator is useful for checking whether a number is even or odd.

For example, number % 2 equals 0 for an even integer.

Remember: / performs division, while % calculates the remainder of integer division. Dividing by zero is not allowed for integer arithmetic.

3. Assignment Operators

Assignment operators allow us to store and update values in variables.

You've already used the basic assignment operator =:

int score = 10;

But C++ also provides shorter ways to update values.

OperatorExampleMeaning
=x = 5Assign 5 to x
+=x += 3Add 3 to x
-=x -= 3Subtract 3 from x
*=x *= 3Multiply x by 3
/=x /= 3Divide x by 3
%=x %= 3Store the remainder

Imagine you're creating a game where a player earns points.

int score = 10;
score += 5;

std::cout << score << "\n";

Output:

15

Instead of writing:

score = score + 5;

We can simply write:

score += 5;

Both have the same effect in this example, but the second version is shorter.

Remember: Compound assignment operators make updating values easier and keep code concise.

4. Comparison Operators

Programs often need to compare values.

For example, a website might check whether someone is old enough to access certain content.

C++ provides comparison operators for this purpose.

OperatorMeaning
==Equal to
!=Not equal to
>Greater than
<Less than
>=Greater than or equal to
<=Less than or equal to

A comparison produces a Boolean result: true or false.

Let's check whether someone is at least 18 years old.

#include <iostream>

int main() {
    int age = 18;
    std::cout << std::boolalpha << (age >= 18) << "\n";

    return 0;
}

Output:

true

The comparison is true because 18 is equal to 18.

Don't Confuse = vs ==

This is one of the most common beginner mistakes!

age = 18;

The = operator assigns a value.

age == 18;

The == operator checks whether two values are equal.

They may look similar, but they perform completely different tasks.

Remember: Use = to assign values and == to compare them.

5. Logical Operators

Sometimes checking just one condition isn't enough. Imagine an event where a visitor must be at least 18 years old and have a ticket. We need to check two conditions at once. That's where logical operators come in.

OperatorNameMeaning
&&ANDTrue when both conditions are true
||ORTrue when at least one condition is true
!NOTReverses a Boolean value

AND Operator (&&)

Both conditions must be true.

int age = 20;
bool hasTicket = true;

std::cout << std::boolalpha << (age >= 18 && hasTicket);

Output:

true

The visitor is old enough and has a ticket, so the combined condition is true.

OR Operator (||)

Only one condition needs to be true.

bool hasStudentCard = true;
bool hasDiscountCode = false;

std::cout << std::boolalpha << (hasStudentCard || hasDiscountCode);

Output:

true

At least one condition is true, so the result is true.

NOT Operator (!)

The NOT operator reverses a Boolean value.

bool isGameOver = false;

std::cout << std::boolalpha << !isGameOver;

Output:

true

Because isGameOver is false, !isGameOver becomes true.

Remember: Logical operators help programs combine conditions and make more complex decisions.

6. Increment and Decrement

Sometimes we simply need to increase or decrease a number by one.

For example, imagine counting how many players have joined a game.

C++ provides two convenient operators:

  • ++ increases a value by 1.
  • -- decreases a value by 1.

Let's see them in action.

int players = 5;

players++;
std::cout << players << "\n";

players--;
std::cout << players << "\n";

Output:

6
5

These operators are especially useful in counters and loops.

Prefix and Postfix

You may also encounter two ways to write these operators:

++players;
players++;

Both increase the variable by one.

However, when used inside larger expressions, they behave differently:

  • ++players increments the variable and produces its updated value.
  • players++ increments the variable but produces its previous value.

For now, using either as a separate statement is straightforward. We'll explore their differences further when learning loops.

7. Operator Precedence

What happens when an expression contains several operators?

Consider this example:

std::cout << 5 + 3 * 2;

Output:

11

Why isn't the answer 16?

Because multiplication has higher precedence than addition.

C++ groups the multiplication first:

5 + (3 * 2) = 11

Using Parentheses

We can change the grouping by adding parentheses.

std::cout << (5 + 3) * 2;

Output:

16

Now the addition is grouped first.

Operator precedence determines how an expression is grouped, but it does not always determine the order in which every part is evaluated.

For beginners, the best habit is simple: use parentheses whenever they make an expression easier to understand.

Clear code is always better than code that makes readers guess.

8. Lesson Summary

Operators are small symbols with an important role in programming. They allow your code to calculate numbers, update values, compare information, and evaluate conditions. You'll use them in almost every program you create. The best way to remember them is through practice. Try changing the numbers and operators in our examples and see how the results change.
