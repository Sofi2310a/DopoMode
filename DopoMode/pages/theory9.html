09 — Pointers

Every variable in a program has a place in memory. But what if you could access that location directly?

In C++, pointers are variables that store memory addresses instead of regular values.

They are one of the most important concepts in C++ and help explain how memory, arrays, functions, and dynamic allocation work behind the scenes.

Let's break them down step by step!

1. What Are Pointers?

A pointer is a variable that stores the memory address of another variable or object.

Instead of holding a number like 42 directly, a pointer holds the address where 42 is stored in memory.

Why are pointers useful?

  • Working with memory — accessing objects through their addresses.
  • Modifying variables inside functions — letting a function update an existing variable directly.
  • Dynamic data structures — building linked lists, trees, and graphs.
  • Performance — accessing large objects without unnecessarily copying them.

Remember: A regular variable stores a value, while a pointer stores a memory address.

2. Memory Addresses

When you create a variable, C++ stores it somewhere in the computer's memory.

You can find a variable's memory address using the address-of operator (&).

#include <iostream>

int main() {
    int number = 42;

    std::cout << "Value: " << number << "\n";
    std::cout << "Address: " << &number << "\n";

    return 0;
}

Example Output:

Value: 42
Address: 0x7ffee4b2c8ac

The exact address looks like a hexadecimal number and may change every time you run the program.

Remember: &variable gives you the memory address where that variable is stored.

3. Creating a Pointer

To create a pointer, write the data type of the object it points to, followed by an asterisk (*).

int number = 42;
int* ptr = &number;

Here:

  • int* means "pointer to an int".
  • ptr is the pointer's name.
  • &number gets the address of number and stores it in ptr.
#include <iostream>

int main() {
    int number = 42;
    int* ptr = &number;

    std::cout << "Address of number: " << &number << "\n";
    std::cout << "Value stored in ptr: " << ptr << "\n";

    return 0;
}

Example Output:

Address of number: 0x7ffee4b2c8ac
Value stored in ptr: 0x7ffee4b2c8ac

Both lines print the same address because ptr points to number.

Remember: * is used to declare a pointer, and & gets the address of an object.

4. Dereferencing Pointers

Once a pointer stores an address, you can access the value at that address using the dereference operator (*).

Dereferencing a pointer means accessing the object it points to.

#include <iostream>

int main() {
    int number = 42;
    int* ptr = &number;

    std::cout << "Address: " << ptr << "\n";
    std::cout << "Value: " << *ptr << "\n";

    return 0;
}

Output:

Address: 0x7ffee4b2c8ac
Value: 42

Changing a Value Through a Pointer

You can also modify the original variable through the pointer.

int number = 42;
int* ptr = &number;

*ptr = 100;

std::cout << "Updated number: " << number << "\n";

Output:

Updated number: 100

Changing *ptr updates number directly because both refer to the same memory location.

Remember: ptr gives the address, while *ptr accesses the value at that address.

5. Null Pointers

Sometimes a pointer shouldn't point to anything yet.

In modern C++, we initialize an empty pointer with nullptr.

int* ptr = nullptr;

A null pointer doesn't point to a valid object. You should always check it before attempting to access anything through it.

#include <iostream>

int main() {
    int* ptr = nullptr;

    if (ptr != nullptr) {
        std::cout << *ptr << "\n";
    } else {
        std::cout << "Pointer is null!\n";
    }

    return 0;
}

Output:

Pointer is null!

Never dereference a null pointer — doing so causes undefined behavior and usually crashes the program.

Remember: Initialize unused pointers to nullptr and check before dereferencing.

6. Pointers and Functions

By default, C++ passes arguments by value, which means a function receives a copy of the variable.

With pointers, a function can receive a variable's address and modify the original variable.

#include <iostream>

void doubleValue(int* value) {
    *value = (*value) * 2;
}

int main() {
    int number = 10;
    doubleValue(&number);

    std::cout << "Number: " << number << "\n";

    return 0;
}

Output:

Number: 20

How Does It Work?

  • &number passes the address of number into the function.
  • int* value receives that address.
  • *value modifies the original variable in main().

Remember: Passing a pointer allows a function to modify the original object through its address.

7. Pointers and Arrays

In many expressions, an array's name decays to a pointer to its first element.

#include <iostream>

int main() {
    int numbers[3] = {10, 20, 30};
    int* ptr = numbers;

    std::cout << *ptr << "\n";
    std::cout << *(ptr + 1) << "\n";
    std::cout << *(ptr + 2) << "\n";

    return 0;
}

Output:

10
20
30

What's Happening Here?

  • ptr points to numbers[0].
  • ptr + 1 moves to the next int in memory (numbers[1]).
  • ptr + 2 moves to numbers[2].

Note that arrays and pointers are not identical — for example, sizeof(numbers) gives the size of the whole array, while sizeof(ptr) gives the size of the pointer itself — even though they are closely connected!

Remember: Pointer arithmetic can move through elements of the same array, but dereferencing outside the array is invalid.

8. Dynamic Memory

Usually, variables are created automatically and destroyed when their scope ends.

C++ also allows us to allocate memory dynamically during program execution using new and release it with delete.

#include <iostream>

int main() {
    int* ptr = new int;
    *ptr = 25;

    std::cout << "Dynamic value: " << *ptr << "\n";

    delete ptr;
    ptr = nullptr;

    return 0;
}

Output:

Dynamic value: 25

How Does It Work?

  • new int allocates memory on the heap for one int and returns its address.
  • *ptr = 25 stores a value in that memory.
  • delete ptr destroys the object and frees the memory when you're done.
  • ptr = nullptr avoids leaving a dangling pointer behind.

What Is a Memory Leak?

If dynamically allocated memory is never freed with delete, it stays reserved until the program exits. This is called a memory leak.

In modern C++, smart pointers like std::unique_ptr are often preferred because they clean up memory automatically.

Remember: Every raw new should be paired with a matching delete (and new[] with delete[]).

9. Common Pointer Mistakes

Pointers are powerful, so small mistakes can cause serious bugs.

Uninitialized Pointers

Never use a pointer before assigning it a valid address or nullptr.

int* ptr; // Uninitialized!
// *ptr = 10; // Undefined behavior!

This local pointer has an indeterminate value. Dereferencing it before initialization can cause undefined behavior.

Dangling Pointers

A dangling pointer refers to an object that no longer exists, such as memory that has already been freed.

int* ptr = new int(5);
delete ptr;
// *ptr = 10; // Do not dereference after delete!
ptr = nullptr;

After calling delete, do not use the old address again; you can reset the pointer to nullptr.

Accessing Invalid Memory

Trying to access memory outside valid objects or arrays can crash your program or corrupt data.

For example:

int numbers[3] = {10, 20, 30};
int* ptr = numbers;
// *(ptr + 5) = 99; // Out of bounds!

Remember: Initialize pointers properly, avoid dangling pointers, and never dereference invalid addresses.
