01 — C++ Basics

Welcome to C++! If you've never written a line of code before, you're in the right place.

In this lesson, we'll go from a blank file to a working program. Along the way, you'll discover what C++ is, how it works, and how to write your first instructions for a computer.

Don't worry if some things seem unfamiliar at first. Every experienced programmer started exactly where you are now.

The secret to learning programming isn't memorizing commands. It's understanding what they do, experimenting with code, and discovering how everything works together.

Ready? Let's get started!

1. What Is C++?

C++ is a powerful programming language used to create software, video games, applications, and systems that control electronic devices.

But what exactly is a programming language?

Imagine you want your computer to calculate something, display a message, or react when someone presses a button. A computer won't know what you want unless you give it instructions.

That's where programming languages come in.

A programming language allows us to write instructions that tell a computer what tasks to perform.

For example, using C++, we can create a program that:

  • Displays a welcome message.
  • Calculates the price of several products.
  • Asks a user to enter information.
  • Controls the movement of a character in a video game.
  • Communicates with sensors and electronic devices.

These examples might seem very different, but they all share one idea: a programmer writes instructions, and the computer executes them.

Where Is C++ Used?

You might be surprised by how many different areas use C++.

Game Development: C++ is widely used to develop video games and game engines. It helps programmers create systems that handle graphics, physics, character movement, and other demanding tasks.

Software Development: Many desktop applications and professional software tools use C++. It is especially useful when programs need to process information efficiently.

Operating Systems: C++ can be used to develop operating system components, system utilities, and software that communicates closely with computer hardware.

Robotics: Robots need software to process information from sensors, control motors, and make decisions. C++ is one of the languages used to build these systems.

Embedded Systems: C++ is also used in devices such as smart electronics, industrial controllers, and other hardware-based systems.

Why Do Programmers Choose C++?

One of the biggest advantages of C++ is performance.

C++ allows programmers to create efficient software and gives them detailed control over how a program uses memory and other computer resources.

However, this control also comes with responsibility. Programmers need to understand how their code works to avoid mistakes.

That's why learning the fundamentals is so important.

Remember: C++ is more than a language for writing commands. It's a tool for turning your ideas into working software.

2. How Does C++ Work?

Before we write our first program, let's understand what happens to C++ code after we create it.

When you write C++ instructions, your computer cannot normally execute that source code directly.

Computers execute machine instructions, so our C++ code needs to be translated into a form that the computer can run.

A tool called a compiler plays an important role in this process.

What Is a Compiler?

A compiler is a program that checks and translates source code into a lower-level form.

For a typical beginner C++ application, the process looks like this:

Source Code → Compilation → Linking → Executable Program → Result

Let's explore each step.

Step 1: Writing Source Code

First, we write instructions in C++.

These instructions are saved in a source file, usually with the .cpp extension.

For example:

main.cpp

Step 2: Compilation

The compiler processes our C++ code.

It checks whether the code follows the language rules and translates it into a form that can be used to build the final program.

If the compiler finds certain errors, such as missing punctuation or an unknown variable name, it reports them.

Step 3: Linking

After compilation, a tool called a linker combines the compiled code with other code the program needs.

This helps produce the finished executable program.

Many development environments perform compilation and linking together when you select the Build command.

Step 4: Running the Program

Once the program is successfully built, we can launch it.

The computer executes its instructions and performs the tasks we programmed.

A Simple Example

Imagine writing a program that displays: Hello, World!

You first write the C++ instructions, build the program, and then run it.

When the program executes, the message appears on the screen. That's the basic idea behind how our first C++ programs will work.

Hello, World!

Can a Compiler Find Every Mistake?

Not quite.

A compiler can identify many problems in your code, but it cannot always determine whether your program does what you intended.

For example, if you accidentally add two numbers when you meant to multiply them, the code may compile successfully and still produce the wrong answer.

That's why programmers don't just write code. They also test it.

Remember: Compilation helps turn C++ code into a working program, but testing helps us check whether the program behaves correctly.

3. Tools for Writing C++

Now that you understand how C++ programs work, let's look at the tools you'll need to create them.

Fortunately, you don't need complicated equipment or expensive software to start programming. You mainly need a place to write code and a way to compile it.

Code Editor

A code editor is an application where programmers write and modify source code. Think of it as a text editor designed specifically for programming.

Unlike ordinary text editors, programming editors often include helpful features such as syntax highlighting, automatic indentation, and code suggestions.

Compiler

A compiler processes your C++ source code and translates it as part of the process of building a program.

Without a suitable compiler or build environment, you usually won't be able to turn your C++ code into an executable application.

IDE — Integrated Development Environment

An IDE (Integrated Development Environment) combines several programming tools in one application.

An IDE may include:

  • A code editor.
  • Tools for compiling and building programs.
  • A debugger for finding problems.
  • Project management features.
  • Code suggestions and navigation tools.

Using an IDE can make programming more convenient because you can perform most tasks in one place.

Popular Tools for C++

Visual Studio: A powerful development environment commonly used for C++ programming on Windows. It includes many tools for creating, building, testing, and debugging applications.

Visual Studio Code: A lightweight and flexible code editor. It supports C++ development through extensions and requires a suitable compiler and development tools to be configured separately.

What Is a .cpp File?

C++ source code is commonly saved in files with the .cpp extension.

For example:

main.cpp

Here, main is the filename, and .cpp identifies it as a C++ source file.

You can create many different .cpp files in a larger project, but we'll start with just one.

Your First Step

Open your preferred C++ development environment and create a new console project or source file.

Name the file: main.cpp

We will use this file to write our first program.

Remember: A code editor helps you write instructions, a compiler helps translate them, and an IDE can bring these tools together.

Let's Write the Program

Enter the following code into your main.cpp file: 

#include <iostream>

int main() {
    std::cout << "Hello, World!\n";
    return 0;
}

Now build and run the program.

If everything is configured correctly, you'll see:

Output:

Hello, World!

Congratulations! You've created a complete C++ program.
