07 — Functions

Imagine writing the same calculation or message logic in ten different places.

Copying the same code repeatedly takes time and makes programs harder to update when something changes.

In C++, functions let you group instructions into reusable blocks that can be called whenever you need them.

In this lesson, you'll learn how to create functions, pass information into them, return values, and organize your code more cleanly.

1. What Are Functions?

A function is a reusable block of code designed to perform a specific task.

For example, a function might display a greeting, calculate a total score, or check whether a player has enough points.

Functions help you:

  • Avoid repetition — write code once and reuse it in multiple places.
  • Stay organized — divide large programs into smaller, easier-to-read parts.
  • Find mistakes faster — fix or update logic in one place instead of searching everywhere.
  • Test and debug — verify each part of your program independently.

Remember: A function groups a specific action so you can reuse it whenever needed.

2. Creating a Function

Let's create a simple function that displays a greeting.

#include <iostream>

void greet() {
    std::cout << "Hello, World!\n";
}

int main() {
    greet();
    greet();

    return 0;
}

Output:

Hello, World!
Hello, World!

How Does It Work?

  • void means the function does not return a value.
  • greet is the function's name.
  • () holds parameters (empty here because no extra input is needed).
  • { ... } contains the instructions that run when the function is called.
  • greet(); inside main() is a function call.

Every time we call greet, the program executes the instructions inside that function.

Remember: Defining a function tells C++ what it does; calling a function actually runs it.

3. Parameters and Arguments

Functions become even more flexible when you pass information into them.

For example, let's greet different people by name.

#include <iostream>
#include <string>

void greet(std::string name) {
    std::cout << "Hello, " << name << "!\n";
}

int main() {
    greet("Alex");
    greet("Emma");

    return 0;
}

Output:

Hello, Alex!
Hello, Emma!

What's the Difference?

  • A parameter is a variable listed in the function definition, such as std::string name in void greet(std::string name).
  • An argument is the actual value passed when calling the function, such as "Alex" or "Emma".

Multiple Parameters

A function can take more than one parameter, separated by commas.

void showSum(int a, int b) {
    std::cout << "Sum: " << (a + b) << "\n";
}

Calling the function:

showSum(5, 3);

Output:

Sum: 8

The arguments are matched to the parameters in order: 5 goes to a, and 3 goes to b.

Remember: Parameters are placeholders in the definition; arguments are the real values passed on call.

4. Returning Values

Sometimes a function should calculate something and send the result back instead of only printing it.

To do that, specify a return type and use the return keyword.

#include <iostream>

int add(int a, int b) {
    return a + b;
}

int main() {
    int result = add(4, 6);
    std::cout << "Result: " << result << "\n";
    std::cout << "Another sum: " << add(10, 15) << "\n";

    return 0;
}

Output:

Result: 10
Another sum: 25

What's the Difference Between void and int?

  • A void function performs an action without sending a value back.
  • A function with a return type like int, double, or std::string sends a value of that type back to the caller using return.
  • std::cout displays information on screen, while return sends a value back to the calling code.

Remember: Use return to send a result back from a function so it can be stored or used in expressions.

5. Function Overloading

In C++, you can create multiple functions with the same name as long as their parameter lists differ in type or number.

This feature is called function overloading.

#include <iostream>

int add(int a, int b) {
    return a + b;
}

double add(double a, double b) {
    return a + b;
}

int add(int a, int b, int c) {
    return a + b + c;
}

int main() {
    std::cout << add(2, 3) << "\n";
    std::cout << add(2.5, 3.5) << "\n";
    std::cout << add(1, 2, 3) << "\n";

    return 0;
}

Output:

5
6
6

C++ automatically picks the matching version based on the arguments you pass.

Note that changing only the return type is not enough for a valid overload.

Remember: Overloaded functions share a name but differ in their parameters.

6. Local and Global Variables

Where you declare a variable determines where in the program you can access it. This is called scope.

Local Variables

A local variable is declared inside a function or another block of code and can only be used inside that block.

void showNumber() {
    int number = 42;
    std::cout << number << "\n";
}

number belongs to showNumber(). Trying to use number directly from main() causes a compiler error.

Local variables help keep different parts of a program independent and safe from accidental changes.

Global Variables

A global variable is declared outside all functions and can be accessed throughout the file after its declaration.

#include <iostream>

int score = 0;

void showScore() {
    std::cout << "Score: " << score << "\n";
}

int main() {
    score = 10;
    showScore();

    return 0;
}

Output:

Score: 10

While global variables are convenient in small examples, relying on them too much can make large programs harder to track because many parts of the code can modify shared data.

Remember: Prefer local variables and pass values through parameters when possible.

7. Function Declarations

In C++, a function or variable must generally be declared before it is used in the code above it.

If you want to place function definitions below main(), you can write a function declaration (also called a function prototype) at the top.

#include <iostream>

int multiply(int a, int b);

int main() {
    std::cout << multiply(3, 4) << "\n";
    return 0;
}

int multiply(int a, int b) {
    return a * b;
}

Output:

12

The declaration tells the compiler the function's name, return type, and parameter types before main() runs, while the full body appears later.

This is especially helpful when organizing larger files or keeping main() near the top.

Remember: A function declaration introduces the signature before the full definition is provided.

8. Recursion

Recursion happens when a function calls itself to solve a problem by breaking it into smaller pieces.

#include <iostream>

void countdown(int number) {
    if (number <= 0) {
        return;
    }

    std::cout << number << " ";
    countdown(number - 1);
}

int main() {
    countdown(5);
    std::cout << "\n";

    return 0;
}

Output:

5 4 3 2 1

How Does It Work?

  • The base case (if (number <= 0) return;) stops the recursion so it doesn't repeat forever.
  • Each call runs with a smaller value (number - 1) until it reaches the stopping condition.
  • Without a base case, a recursive function keeps calling itself until the program runs out of memory (a stack overflow).

Remember: Every recursive function needs a clear stopping condition (base case).
