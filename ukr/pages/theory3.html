03 — Оператори

Тепер, коли ти знаєш, як зберігати інформацію у змінних, настав час дізнатися, що з нею можна робити!

У цьому уроці ти дізнаєшся, як C++ виконує обчислення, порівнює значення та працює з умовами.

Ці операції необхідні для всього — від простих калькуляторів до інтерактивних ігор.

1. Що таке оператори?

Оператори — це символи, які наказують C++ виконати дію над значеннями або змінними.

Наприклад, оператор + додає два числа:

#include <iostream>

int main() {
    int result = 10 + 5;
    std::cout << result << "\n";

    return 0;
}

Вивід:

15

Тут 10 і 5 — значення, з якими ми працюємо, а + — оператор.

C++ надає різні оператори для обчислень, порівнянь, оновлення змінних і об’єднання умов.

Розгляньмо найкорисніші з них.

2. Арифметичні оператори

Арифметичні оператори дозволяють виконувати математичні обчислення.

ОператорОпераціяПрикладРезультат
+Додавання5 + 38
-Віднімання5 - 32
*Множення5 * 315
/Ділення10 / 25
%Остача10 % 31

Спробуймо їх у програмі:

#include <iostream>

int main() {
    int a = 10;
    int b = 3;

    std::cout << "Sum: " << a + b << "\n";
    std::cout << "Division: " << a / b << "\n";
    std::cout << "Remainder: " << a % b << "\n";

    return 0;
}

Вивід:

Sum: 13
Division: 3
Remainder: 1

Цілочисельне ділення

Зверни увагу на цікавий факт: 10 / 3 дає 3, а не 3.33.

Це тому, що обидва числа цілі. Під час ділення двох цілих чисел C++ відкидає дробову частину результату. Щоб отримати десятковий результат, використовуй числа з плаваючою комою:

double result = 10.0 / 3.0;
std::cout << result << "\n";

Вивід (зі стандартним форматуванням):

3.33333

Що робить %?

Оператор % повертає остачу від цілочисельного ділення.

Наприклад:

std::cout << 10 % 3;

Вивід:

1

Чому? Тому що 3 вміщується в 10 тричі, залишаючи остачу 1.

Цей оператор корисний для перевірки, парне число чи непарне.

Наприклад, number % 2 дорівнює 0 для парного цілого числа.

Пам’ятай: / виконує ділення, а % обчислює остачу від цілочисельного ділення. Ділити на нуль у цілочисельній арифметиці не можна.

3. Оператори присвоєння

Оператори присвоєння дозволяють зберігати та оновлювати значення у змінних.

Ти вже використовував базовий оператор присвоєння =:

int score = 10;

Але C++ також надає коротші способи оновлення значень.

ОператорПрикладЗначення
=x = 5Присвоїти x значення 5
+=x += 3Додати 3 до x
-=x -= 3Відняти 3 від x
*=x *= 3Помножити x на 3
/=x /= 3Поділити x на 3
%=x %= 3Зберегти остачу

Уяви, що ти створюєш гру, у якій гравець заробляє бали.

int score = 10;
score += 5;

std::cout << score << "\n";

Вивід:

15

Замість того щоб писати:

score = score + 5;

Можна просто написати:

score += 5;

У цьому прикладі обидва варіанти дають однаковий результат, але другий коротший.

Пам’ятай: складені оператори присвоєння полегшують оновлення значень і роблять код лаконічним.

4. Оператори порівняння

Програмам часто потрібно порівнювати значення.

Наприклад, вебсайт може перевіряти, чи достатньо людині років, щоб отримати доступ до певного вмісту.

Для цього C++ надає оператори порівняння.

ОператорЗначення
==Дорівнює
!=Не дорівнює
>Більше
<Менше
>=Більше або дорівнює
<=Менше або дорівнює

Порівняння повертає логічний результат: true або false.

Перевірімо, чи людині щонайменше 18 років.

#include <iostream>

int main() {
    int age = 18;
    std::cout << std::boolalpha << (age >= 18) << "\n";

    return 0;
}

Вивід:

true

Порівняння істинне, тому що 18 дорівнює 18.

Не плутай = та ==

Це одна з найпоширеніших помилок початківців!

age = 18;

Оператор = присвоює значення.

age == 18;

Оператор == перевіряє, чи рівні два значення.

Вони можуть виглядати схожими, але виконують зовсім різні завдання.

Пам’ятай: використовуй =, щоб присвоювати значення, і ==, щоб порівнювати їх.

5. Логічні оператори

Іноді перевірки лише однієї умови недостатньо. Уяви захід, на який відвідувач повинен мати щонайменше 18 років і квиток. Нам потрібно перевірити дві умови одночасно. Саме тут на допомогу приходять логічні оператори.

ОператорІм’яЗначення
&&І (AND)Істинно, коли обидві умови істинні
||АБО (OR)Істинно, коли істинна принаймні одна умова
!НЕ (NOT)Змінює логічне значення на протилежне

Оператор AND (&&)

Обидві умови мають бути істинними.

int age = 20;
bool hasTicket = true;

std::cout << std::boolalpha << (age >= 18 && hasTicket);

Вивід:

true

Відвідувач достатньо дорослий і має квиток, тому складена умова істинна.

Оператор OR (||)

Достатньо, щоб істинною була лише одна умова.

bool hasStudentCard = true;
bool hasDiscountCode = false;

std::cout << std::boolalpha << (hasStudentCard || hasDiscountCode);

Вивід:

true

Принаймні одна умова істинна, тому результат істинний.

Оператор NOT (!)

Оператор NOT змінює логічне значення на протилежне.

bool isGameOver = false;

std::cout << std::boolalpha << !isGameOver;

Вивід:

true

Оскільки isGameOver дорівнює false, !isGameOver стає true.

Пам’ятай: логічні оператори допомагають програмам поєднувати умови та ухвалювати складніші рішення.

6. Інкремент і декремент

Іноді нам просто потрібно збільшити або зменшити число на одиницю.

Наприклад, уяви, що ми рахуємо, скільки гравців приєдналося до гри.

C++ надає два зручні оператори:

  • ++ збільшує значення на 1.
  • -- зменшує значення на 1.

Подивімося на них у дії.

int players = 5;

players++;
std::cout << players << "\n";

players--;
std::cout << players << "\n";

Вивід:

6
5

Ці оператори особливо корисні в лічильниках і циклах.

Префіксна та постфіксна форми

Ти також можеш зустріти два способи запису цих операторів:

++players;
players++;

Обидва збільшують змінну на одиницю.

Проте, коли їх використовують усередині складніших виразів, вони поводяться по-різному:

  • ++players збільшує змінну та повертає її оновлене значення.
  • players++ збільшує змінну, але повертає її попереднє значення.

Поки що використання будь-якої з них як окремої інструкції не викликає складнощів. Докладніше їхню різницю ми розглянемо під час вивчення циклів.

7. Пріоритет операторів

Що відбувається, коли вираз містить кілька операторів?

Розглянь такий приклад:

std::cout << 5 + 3 * 2;

Вивід:

11

Чому відповідь не 16?

Тому що множення має вищий пріоритет, ніж додавання.

C++ спочатку групує множення:

5 + (3 * 2) = 11

Використання дужок

Ми можемо змінити групування, додавши дужки.

std::cout << (5 + 3) * 2;

Вивід:

16

Тепер спочатку групується додавання.

Пріоритет операторів визначає, як групується вираз, але не завжди визначає порядок обчислення кожної його частини.

Для початківців найкраща звичка проста: використовуй дужки щоразу, коли вони роблять вираз легшим для розуміння.

Зрозумілий код завжди кращий за код, який змушує читача вгадувати.

8. Підсумок уроку

Оператори — це невеликі символи з важливою роллю в програмуванні. Вони дозволяють коду обчислювати числа, оновлювати значення, порівнювати інформацію та оцінювати умови. Ти використовуватимеш їх майже в кожній програмі, яку створиш. Найкращий спосіб запам’ятати їх — практика. Спробуй змінити числа та оператори в наших прикладах і подивись, як зміняться результати. Наступний урок: 04 — Умови. Тепер, коли ти знаєш, як порівнювати значення та працювати з логічними виразами, ти готовий зробити свої програми розумнішими!

У наступному уроці ти навчишся використовувати if, else та switch, щоб програми обирали різні дії залежно від різних ситуацій.
