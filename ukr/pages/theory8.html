08 — Масиви та рядки

Уяви, що ти пишеш програму, яка зберігає результати 100 гравців.

Створювати 100 окремих змінних, як-от score1, score2, score3..., було б не дуже практично, правда?

У C++ масиви дозволяють зберігати кілька значень одного типу в одній колекції, а рядки — легше працювати з текстом.

Дослідімо обидва!

1. Що таке масиви?

Масив — це колекція елементів одного типу даних, що зберігаються разом у певному порядку.

Замість створення п’яти змінних для п’яти результатів тестів можна використати один масив.

int scores[5] = {90, 85, 78, 92, 88};

Тут:

  • int — тип даних кожного елемента.
  • scores — ім’я масиву.
  • [5] вказує, що масив може містити 5 елементів.
  • {90, 85, 78, 92, 88} задає початкові значення.

Пам’ятай: усі елементи масиву в C++ повинні мати однаковий тип даних.

2. Доступ до елементів масиву

Кожен елемент масиву має індекс — свою позицію в списку.

У C++ індексація масивів починається з 0, а не з 1.

Тож для масиву з 5 елементів допустимі індекси: 0, 1, 2, 3 і 4.

#include <iostream>

int main() {
    int scores[5] = {90, 85, 78, 92, 88};

    std::cout << "First score: " << scores[0] << "\n";
    std::cout << "Second score: " << scores[1] << "\n";

    return 0;
}

Вивід:

First score: 90
Second score: 85

Зміна елемента

Ти можеш оновити елемент масиву за його індексом, так само як звичайну змінну.

scores[1] = 95;
std::cout << "Updated second score: " << scores[1] << "\n";

Вивід:

Updated second score: 95

Тепер другий елемент містить 95 замість 85.

Пам’ятай: перший елемент завжди має індекс 0.

3. Масиви та цикли

Масиви та цикли природно працюють разом, адже цикли можуть по черзі відвідувати кожен елемент.

#include <iostream>

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};

    for (int i = 0; i < 5; i++) {
        std::cout << numbers[i] << " ";
    }

    return 0;
}

Вивід:

10 20 30 40 50

Змінна циклу i змінюється від 0 до 4, звертаючись до numbers[0], numbers[1], numbers[2], numbers[3] і numbers[4].

Цикл for за діапазоном

C++ також пропонує простіший синтаксис циклу для проходу по елементах масиву.

int numbers[5] = {10, 20, 30, 40, 50};

for (int n : numbers) {
    std::cout << n << " ";
}

Вивід:

10 20 30 40 50

Це називається циклом for за діапазоном (range-based for). Він автоматично відвідує кожен елемент, роблячи код коротшим і легшим для читання.

Пам’ятай: цикли дозволяють ефективно виводити, обробляти або оновлювати кожен елемент масиву.

4. Розмір масиву та типові помилки

Вбудований масив C++ має фіксований розмір після створення.

int numbers[3] = {5, 10, 15};

Цей масив містить рівно три елементи з індексами 0, 1 і 2.

Що станеться, якщо ми спробуємо звернутися до numbers[5]?

Це вихід за межі масиву — читання або запис неіснуючого елемента! Програма може показати сміттєві значення, аварійно завершитися або поводитися непередбачувано.

Важливо: завжди залишайся в межах допустимих індексів масиву від 0 до size - 1. Для колекцій, розмір яких динамічно змінюється під час роботи програми, сучасний C++ також пропонує std::vector.

5. Багатовимірні масиви

Масиви можуть мати більше одного виміру. Двовимірний масив можна уявити як таблицю з рядками та стовпцями.

int grid[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

Тут grid має 2 рядки та 3 стовпці.

  • Рядок 0 містить 1, 2, 3.
  • Рядок 1 містить 4, 5, 6.

Перший індекс вибирає рядок, а другий — стовпець. Наприклад, grid[1][2] дорівнює 6.

Використання вкладених циклів

Вкладені цикли часто використовують для проходу по всіх елементах двовимірного масиву.

for (int row = 0; row < 2; row++) {
    for (int col = 0; col < 3; col++) {
        std::cout << grid[row][col] << " ";
    }
    std::cout << "\n";
}

Вивід:

1 2 3
4 5 6

Пам’ятай: двовимірні масиви корисні для таблиць, ігрових полів і сіток.

6. Що таке рядки?

У C++ текст зазвичай зберігають за допомогою std::string із заголовка <string>.

#include <iostream>
#include <string>

int main() {
    std::string greeting = "Hello, C++!";
    std::cout << greeting << "\n";

    return 0;
}

Вивід:

Hello, C++!

char проти std::string

Пам’ятаєш char з уроку про типи даних?

  • char містить один символ, наприклад 'A'.
  • std::string містить послідовність символів, наприклад "Apple" або ціле речення.

std::string набагато гнучкіший за «сирі» масиви символів для повсякденної роботи з текстом.

Пам’ятай: підключай <string>, коли використовуєш std::string.

7. Робота з рядками

std::string робить поширені операції з текстом простими.

Об’єднання рядків

Ти можеш з’єднувати рядки за допомогою оператора +.

std::string firstName = "Alex";
std::string lastName = "Smith";
std::string fullName = firstName + " " + lastName;

std::cout << fullName << "\n";

Вивід:

Alex Smith

Визначення довжини рядка

Функція length() повертає кількість елементів у рядку.

std::string text = "Hello";
std::cout << text.length() << "\n";

Вивід:

5

Для звичайного англійського тексту length() збігається з кількістю символів. Для тексту з діакритичними знаками, емодзі або багатобайтовими символами UTF-8 зауваж, що length() рахує байти/кодові одиниці, а не візуальні символи.

Доступ до символів

Так само, як і в масиві, рядок дозволяє звертатися до окремих символів за індексами, що починаються з 0.

std::string word = "Hello";
std::cout << word[0] << "\n";

Вивід:

H

Ти також можеш змінити символ за індексом:

std::string word = "Hello";
word[0] = 'J';
std::cout << word << "\n";

Вивід:

Jello

Будь обережним і не використовуй індекс поза допустимим діапазоном, адже це може призвести до невизначеної поведінки.

Пам’ятай: рядки дозволяють поєднувати текст, дізнаватися його довжину та звертатися до символів за індексом.

8. Читання рядків від користувача

Використання std::cin >> із рядком зупиняє читання на пробільному символі (такому як пробіл, табуляція чи новий рядок).

std::string firstName;
std::cout << "Enter your first name: ";
std::cin >> firstName;

А що, якщо користувач вводить повне ім’я з пробілами?

Читання цілого рядка

Щоб прочитати повний рядок разом із пробілами, використовуй std::getline(std::cin, variable).

#include <iostream>
#include <string>

int main() {
    std::string fullName;

    std::cout << "Enter your full name: ";
    std::getline(std::cin, fullName);

    std::cout << "Hello, " << fullName << "!\n";

    return 0;
}

Приклад виводу:

Enter your full name: Alex Smith
Hello, Alex Smith!

Тепер програма може читати ввід із кількох слів, наприклад Alex Smith, не обриваючи його на першому пробілі.

Пам’ятай: використовуй std::getline, коли хочеш прочитати цілий рядок, що може містити пробіли.
