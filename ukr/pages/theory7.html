07 — Функції

Уяви, що ти пишеш одне й те саме обчислення або логіку повідомлення в десяти різних місцях.

Багаторазове копіювання одного й того самого коду забирає час і ускладнює оновлення програм, коли щось змінюється.

У C++ функції дозволяють групувати інструкції в багаторазові блоки, які можна викликати, коли вони потрібні.

У цьому уроці ти навчишся створювати функції, передавати в них інформацію, повертати значення та чистіше організовувати свій код.

1. Що таке функції?

Функція — це багаторазовий блок коду, призначений для виконання конкретного завдання.

Наприклад, функція може виводити привітання, обчислювати загальний бал або перевіряти, чи достатньо в гравця очок.

Функції допомагають:

  • Уникати повторень — пиши код один раз і використовуй його в кількох місцях.
  • Тримати порядок — ділити великі програми на менші, легші для читання частини.
  • Швидше знаходити помилки — виправляти або оновлювати логіку в одному місці, а не шукати скрізь.
  • Тестувати й налагоджувати — перевіряти кожну частину програми окремо.

Пам’ятай: функція групує певну дію, щоб ти міг використовувати її знову, коли потрібно.

2. Створення функції

Створімо просту функцію, яка виводить привітання.

#include <iostream>

void greet() {
    std::cout << "Hello, World!\n";
}

int main() {
    greet();
    greet();

    return 0;
}

Вивід:

Hello, World!
Hello, World!

Як це працює?

  • void означає, що функція не повертає значення.
  • greet — це ім’я функції.
  • () містить параметри (тут порожні, бо додаткові дані не потрібні).
  • { ... } містить інструкції, які виконуються під час виклику функції.
  • greet(); усередині main() — це виклик функції.

Щоразу, коли ми викликаємо greet, програма виконує інструкції всередині цієї функції.

Пам’ятай: визначення функції каже C++, що вона робить; виклик функції фактично її запускає.

3. Параметри та аргументи

Функції стають ще гнучкішими, коли ти передаєш у них інформацію.

Наприклад, привітаймо різних людей на ім’я.

#include <iostream>
#include <string>

void greet(std::string name) {
    std::cout << "Hello, " << name << "!\n";
}

int main() {
    greet("Alex");
    greet("Emma");

    return 0;
}

Вивід:

Hello, Alex!
Hello, Emma!

У чому різниця?

  • Параметр — це змінна, указана у визначенні функції, наприклад std::string name у void greet(std::string name).
  • Аргумент — це фактичне значення, що передається під час виклику функції, наприклад "Alex" або "Emma".

Кілька параметрів

Функція може приймати більше одного параметра, розділеного комами.

void showSum(int a, int b) {
    std::cout << "Sum: " << (a + b) << "\n";
}

Виклик функції:

showSum(5, 3);

Вивід:

Sum: 8

Аргументи зіставляються з параметрами за порядком: 5 потрапляє в a, а 3 — у b.

Пам’ятай: параметри — це заповнювачі у визначенні; аргументи — це реальні значення, що передаються під час виклику.

4. Повернення значень

Іноді функція має щось обчислити й повернути результат, а не лише вивести його.

Для цього вкажи тип повернення та використай ключове слово return.

#include <iostream>

int add(int a, int b) {
    return a + b;
}

int main() {
    int result = add(4, 6);
    std::cout << "Result: " << result << "\n";
    std::cout << "Another sum: " << add(10, 15) << "\n";

    return 0;
}

Вивід:

Result: 10
Another sum: 25

У чому різниця між void та int?

  • Функція void виконує дію, не повертаючи значення.
  • Функція з типом повернення, як-от int, double чи std::string, повертає значення цього типу викликачу за допомогою return.
  • std::cout виводить інформацію на екран, а return повертає значення в код, що викликав функцію.

Пам’ятай: використовуй return, щоб повернути результат із функції, щоб його можна було зберегти або використати у виразах.

5. Перевантаження функцій

У C++ можна створювати кілька функцій з однаковим іменем, якщо їхні списки параметрів відрізняються за типом або кількістю.

Ця можливість називається перевантаженням функцій.

#include <iostream>

int add(int a, int b) {
    return a + b;
}

double add(double a, double b) {
    return a + b;
}

int add(int a, int b, int c) {
    return a + b + c;
}

int main() {
    std::cout << add(2, 3) << "\n";
    std::cout << add(2.5, 3.5) << "\n";
    std::cout << add(1, 2, 3) << "\n";

    return 0;
}

Вивід:

5
6
6

C++ автоматично обирає відповідну версію на основі переданих аргументів.

Зверни увагу, що зміни лише типу повернення недостатньо для коректного перевантаження.

Пам’ятай: перевантажені функції мають однакове ім’я, але відрізняються параметрами.

6. Локальні та глобальні змінні

Місце, де ти оголошуєш змінну, визначає, де в програмі до неї можна звертатися. Це називається областю видимості.

Локальні змінні

Локальна змінна оголошується всередині функції або іншого блоку коду й може використовуватися лише всередині цього блоку.

void showNumber() {
    int number = 42;
    std::cout << number << "\n";
}

number належить showNumber(). Спроба використати number безпосередньо з main() спричиняє помилку компілятора.

Локальні змінні допомагають зберігати різні частини програми незалежними та захищеними від випадкових змін.

Глобальні змінні

Глобальна змінна оголошується поза всіма функціями й доступна в усьому файлі після свого оголошення.

#include <iostream>

int score = 0;

void showScore() {
    std::cout << "Score: " << score << "\n";
}

int main() {
    score = 10;
    showScore();

    return 0;
}

Вивід:

Score: 10

Хоча глобальні змінні зручні в невеликих прикладах, надмірне покладання на них може ускладнити відстеження великих програм, адже багато частин коду можуть змінювати спільні дані.

Пам’ятай: надавай перевагу локальним змінним і передавай значення через параметри, коли це можливо.

7. Оголошення функцій

У C++ функцію або змінну зазвичай потрібно оголосити до її використання в коді вище.

Якщо ти хочеш розмістити визначення функцій нижче main(), можна написати оголошення функції (також називається прототипом функції) на початку.

#include <iostream>

int multiply(int a, int b);

int main() {
    std::cout << multiply(3, 4) << "\n";
    return 0;
}

int multiply(int a, int b) {
    return a * b;
}

Вивід:

12

Оголошення повідомляє компілятору ім’я функції, тип повернення та типи параметрів до запуску main(), а повне тіло з’являється пізніше.

Це особливо корисно під час організації більших файлів або коли main() потрібно залишити ближче до початку.

Пам’ятай: оголошення функції вводить сигнатуру до того, як буде надано повне визначення.

8. Рекурсія

Рекурсія виникає, коли функція викликає саму себе, щоб розв’язати задачу, розбиваючи її на менші частини.

#include <iostream>

void countdown(int number) {
    if (number <= 0) {
        return;
    }

    std::cout << number << " ";
    countdown(number - 1);
}

int main() {
    countdown(5);
    std::cout << "\n";

    return 0;
}

Вивід:

5 4 3 2 1

Як це працює?

  • Базовий випадок (if (number <= 0) return;) зупиняє рекурсію, щоб вона не повторювалася нескінченно.
  • Кожен виклик виконується з меншим значенням (number - 1), доки не досягне умови зупинки.
  • Без базового випадку рекурсивна функція продовжує викликати саму себе, доки в програми не закінчиться пам’ять (переповнення стека).

Пам’ятай: кожна рекурсивна функція потребує чіткої умови зупинки (базового випадку).
