11 — Структури та перелічення

Уяви, що ти створюєш застосунок для зберігання інформації про студентів. Кожен студент має ім’я, вік та оцінку.

Чи не було б зручніше зберігати всю цю інформацію разом, замість того щоб працювати з окремими змінними?

Саме для цього у C++ існують структури (struct)!

У цьому уроці ти навчишся впорядковувати пов’язані дані за допомогою структур і представляти фіксовані набори значень за допомогою перелічень (enum).

1. Що таке структури?

Структура — це власний тип даних, який об’єднує пов’язану інформацію в один об’єкт.

Наприклад, створімо структуру Student:

#include <iostream>
#include <string>

struct Student {
    std::string name;
    int age;
    double grade;
};

int main() {
    Student student1 = {"Alex", 18, 95.5};

    std::cout << student1.name << "\n";
    std::cout << student1.age << "\n";
    std::cout << student1.grade << "\n";

    return 0;
}

Вивід:

Alex
18
95.5

Тут Student — це новий тип даних, який містить три поля:

  • name — зберігає ім’я студента.
  • age — зберігає його вік.
  • grade — зберігає його оцінку.

Змінна student1 — це об’єкт типу Student.

Пам’ятай: структури дозволяють об’єднувати різні типи пов’язаних даних в один об’єкт.

2. Доступ до полів структури

Щоб отримати доступ до інформації, яка зберігається всередині структури, використовують оператор крапки (.).

Створімо структуру, яка представляє автомобіль.

#include <iostream>
#include <string>

struct Car {
    std::string brand;
    int year;
};

int main() {
    Car myCar = {"BMW", 2020};

    std::cout << myCar.brand << "\n";
    std::cout << myCar.year << "\n";

    return 0;
}

Вивід:

BMW
2020

Зміна значень полів

Ми можемо змінювати значення окремих полів структури так само, як і значення звичайних змінних.

myCar.year = 2024;

Тепер поле myCar.year містить значення 2024.

Структура може містити числа, рядки, логічні значення, масиви та навіть інші структури.

Пам’ятай: використовуй оператор крапки, щоб читати або змінювати поля об’єкта структури.

3. Масиви структур

А що, якщо твоєму застосунку потрібно зберігати інформацію про кількох студентів?

Замість створення окремих змінних для кожного студента можна використати масив структур.

#include <iostream>
#include <string>

struct Student {
    std::string name;
    int age;
};

int main() {
    Student students[3] = {
        {"Alex", 18},
        {"Emma", 19},
        {"John", 20}
    };

    for (const Student& student : students) {
        std::cout << student.name << " - "
                  << student.age << "\n";
    }

    return 0;
}

Вивід:

Alex - 18
Emma - 19
John - 20

Кожен елемент масиву — це окремий об’єкт типу Student.

Цикл for на основі діапазону послідовно перебирає всіх студентів, а оператор крапки дозволяє звертатися до їхніх даних.

Ми використовуємо const Student&, щоб читати інформацію про кожного студента без створення зайвої копії об’єкта.

Пам’ятай: масиви структур корисні для роботи з наборами пов’язаних об’єктів.

4. Структури та функції

Структури також можна передавати у функції.

Уяви, що ти хочеш створити функцію, яка відображатиме інформацію про будь-якого студента.

#include <iostream>
#include <string>

struct Student {
    std::string name;
    int age;
};

void showStudent(const Student& student) {
    std::cout << "Name: " << student.name << "\n";
    std::cout << "Age: " << student.age << "\n";
}

int main() {
    Student student1 = {"Alex", 18};

    showStudent(student1);

    return 0;
}

Вивід:

Name: Alex
Age: 18

Навіщо використовувати const Student&?

Функція отримує об’єкт через константне посилання.

  • Student& — дозволяє функції звертатися до наявного об’єкта без його копіювання.
  • const — забороняє функції змінювати цей об’єкт через посилання.

Такий підхід корисний, коли функції потрібно лише прочитати інформацію.

Пам’ятай: передача структур у функції допомагає впорядковувати операції та повторно використовувати код.

5. Що таке перелічення?

Іноді програмі потрібно представити обмежений набір можливих варіантів.

Наприклад, замовлення може очікувати на підтвердження, бути схваленим або відхиленим.

Замість використання незрозумілих чисел ми можемо надати цим станам змістовні назви.

Перелічення (enum) — це тип даних, який визначає набір іменованих значень.

#include <iostream>

enum Day {
    Monday,
    Tuesday,
    Wednesday,
    Thursday,
    Friday
};

int main() {
    Day today = Wednesday;

    std::cout << today << "\n";

    return 0;
}

Вивід:

2

За замовчуванням значення елементів enum починаються з 0 і збільшуються на одиницю:

Назва Значення
Monday 0
Tuesday 1
Wednesday 2
Thursday 3
Friday 4

Використання назв на кшталт Wednesday робить код зрозумілішим, ніж використання чисел без пояснення їхнього значення, наприклад 2.

Пам’ятай: перелічення допомагають представляти набори пов’язаних іменованих значень.

6. enum class

Сучасний C++ пропонує безпечніший спосіб створення перелічень — enum class.

Таке перелічення має власну область імен і забезпечує суворішу перевірку типів.

Створімо перелічення для статусів замовлення.

#include <iostream>

enum class Status {
    Pending,
    Approved,
    Rejected
};

int main() {
    Status order = Status::Approved;

    if (order == Status::Approved) {
        std::cout << "Order approved!\n";
    }

    return 0;
}

Вивід:

Order approved!

Зверни увагу, що ми записуємо:

Status::Approved

Оператор :: вказує, що значення Approved належить переліченню Status.

Порівняння enum та enum class

enum enum class
Елементи перелічення доступні в області видимості, що його містить До елементів звертаються через назву перелічення
Може неявно перетворюватися на цілі числа Не перетворюється неявно на цілі числа
Більший ризик конфліктів імен Кращий захист від конфліктів імен

Пам’ятай: у сучасному C++ варто надавати перевагу enum class, коли потрібно визначити набір чітко встановлених станів або варіантів.

7. Використання перелічень зі switch

Перелічення особливо зручно використовувати разом з оператором switch.

Уяви інтернет-магазин, який показує різні повідомлення залежно від статусу замовлення.

#include <iostream>

enum class Status {
    Pending,
    Approved,
    Rejected
};

int main() {
    Status order = Status::Pending;

    switch (order) {
        case Status::Pending:
            std::cout << "Waiting for approval\n";
            break;

        case Status::Approved:
            std::cout << "Order approved\n";
            break;

        case Status::Rejected:
            std::cout << "Order rejected\n";
            break;
    }

    return 0;
}

Вивід:

Waiting for approval

Оператор switch перевіряє значення змінної order і виконує відповідний блок case.

Такий підхід корисний в іграх, застосунках і системах, які керують різними станами.

Пам’ятай: поєднання enum class і switch робить рішення, що залежать від стану, зрозумілішими та полегшує підтримку коду.

8. Псевдоніми типів за допомогою using

Іноді тип даних має довгу назву або ми хочемо чіткіше показати його призначення.

C++ дозволяє створювати альтернативні назви для типів за допомогою ключового слова using.

#include <iostream>

using Score = double;

int main() {
    Score grade = 95.5;

    std::cout << grade << "\n";

    return 0;
}

Вивід:

95.5

Тут Score — це просто інша назва для типу double.

Вона не створює абсолютно нового типу даних, але може зробити код зрозумілішим.

Наприклад:

using StudentID = int;

StudentID studentNumber = 1025;

Тепер призначення змінної значно легше зрозуміти.

Пам’ятай: псевдоніми типів надають альтернативні назви наявним типам даних, роблячи код зрозумілішим.
