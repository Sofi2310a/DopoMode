11 — Structs & Enums

Imagine you're building an application that stores information about students. Each student has a name, age, and grade.

Wouldn't it be easier to keep all this information together instead of managing separate variables?

That's exactly what structures (struct) allow us to do!

In this lesson, you'll learn how to organize related data using structures and represent fixed sets of values using enumerations (enum).

1. What Are Structures?

A structure is a custom data type that groups related information into one object.

For example, let's create a Student structure:

#include <iostream>
#include <string>

struct Student {
    std::string name;
    int age;
    double grade;
};

int main() {
    Student student1 = {"Alex", 18, 95.5};

    std::cout << student1.name << "\n";
    std::cout << student1.age << "\n";
    std::cout << student1.grade << "\n";

    return 0;
}

Output:

Alex
18
95.5

Here, Student is a new type containing three data members:

  • name — stores the student's name.
  • age — stores their age.
  • grade — stores their grade.

The variable student1 is an object of type Student.

Remember: Structures allow you to combine different types of related information into one object.

2. Accessing Structure Members

To access information stored inside a structure, we use the dot operator (.).

Let's create a structure representing a car.

#include <iostream>
#include <string>

struct Car {
    std::string brand;
    int year;
};

int main() {
    Car myCar = {"BMW", 2020};

    std::cout << myCar.brand << "\n";
    std::cout << myCar.year << "\n";

    return 0;
}

Output:

BMW
2020

Changing Member Values

We can update individual members just like ordinary variables.

myCar.year = 2024;

Now myCar.year contains 2024.

A structure can contain numbers, strings, Boolean values, arrays, and even other structures.

Remember: Use the dot operator to read or modify the members of a structure object.

3. Arrays of Structures

What if your application needs to store information about several students?

Instead of creating individual variables for each student, we can create an array of structures.

#include <iostream>
#include <string>

struct Student {
    std::string name;
    int age;
};

int main() {
    Student students[3] = {
        {"Alex", 18},
        {"Emma", 19},
        {"John", 20}
    };

    for (const Student& student : students) {
        std::cout << student.name << " - "
                  << student.age << "\n";
    }

    return 0;
}

Output:

Alex - 18
Emma - 19
John - 20

Each array element is a separate Student object.

The range-based for loop visits every student, while the dot operator accesses their information.

We use const Student& to read each student without creating an unnecessary copy.

Remember: Arrays of structures are useful when managing collections of related objects.

4. Structures and Functions

Structures can also be passed to functions.

Imagine creating a function that displays information about any student.

#include <iostream>
#include <string>

struct Student {
    std::string name;
    int age;
};

void showStudent(const Student& student) {
    std::cout << "Name: " << student.name << "\n";
    std::cout << "Age: " << student.age << "\n";
}

int main() {
    Student student1 = {"Alex", 18};

    showStudent(student1);

    return 0;
}

Output:

Name: Alex
Age: 18

Why Use const Student&?

The function receives the object through a constant reference.

  • Student& — allows the function to access the existing object without copying it.
  • const — prevents the function from modifying that object through the reference.

This approach is useful when a function only needs to read information.

Remember: Passing structures to functions helps you organize operations and reuse code.

5. What Are Enumerations?

Sometimes a program needs to represent a limited number of possible options.

For example, an order might be pending, approved, or rejected.

Instead of using unexplained numbers, we can give these states meaningful names.

An enumeration (enum) is a type that defines a set of named values.

#include <iostream>

enum Day {
    Monday,
    Tuesday,
    Wednesday,
    Thursday,
    Friday
};

int main() {
    Day today = Wednesday;

    std::cout << today << "\n";

    return 0;
}

Output:

2

By default, enum values start at 0 and increase by one:

Name Value
Monday 0
Tuesday 1
Wednesday 2
Thursday 3
Friday 4

Using names such as Wednesday makes code easier to understand than using unexplained numbers like 2.

Remember: Enumerations help represent a set of related, named values.

6. enum class

Modern C++ provides a safer way to create enumerations using enum class.

It gives enumeration values their own scope and provides stronger type checking.

Let's create an enumeration for order statuses.

#include <iostream>

enum class Status {
    Pending,
    Approved,
    Rejected
};

int main() {
    Status order = Status::Approved;

    if (order == Status::Approved) {
        std::cout << "Order approved!\n";
    }

    return 0;
}

Output:

Order approved!

Notice that we write:

Status::Approved

The :: operator tells C++ that Approved belongs to the Status enumeration.

enum vs enum class

enum enum class
Enumerators are accessible in their enclosing scope Enumerators are accessed through the enum's name
Can implicitly convert to integers Does not implicitly convert to integers
More prone to naming conflicts Better protection against naming conflicts

Remember: Prefer enum class in modern C++ when you need a set of clearly defined states or options.

7. Using Enums with switch

Enumerations work especially well with switch statements.

Imagine an online store that displays different messages depending on an order's status.

#include <iostream>

enum class Status {
    Pending,
    Approved,
    Rejected
};

int main() {
    Status order = Status::Pending;

    switch (order) {
        case Status::Pending:
            std::cout << "Waiting for approval\n";
            break;

        case Status::Approved:
            std::cout << "Order approved\n";
            break;

        case Status::Rejected:
            std::cout << "Order rejected\n";
            break;
    }

    return 0;
}

Output:

Waiting for approval

The switch statement checks the value of order and executes the matching case.

This approach is useful in games, applications, and systems that manage different states.

Remember: Combining enum class with switch makes state-based decisions easier to read and maintain.

8. Type Aliases with using

Sometimes a data type has a long name, or we want to make its purpose clearer.

C++ allows us to create an alternative name using using.

#include <iostream>

using Score = double;

int main() {
    Score grade = 95.5;

    std::cout << grade << "\n";

    return 0;
}

Output:

95.5

Here, Score is simply another name for double.

It doesn't create a completely new type, but it can make our code more descriptive.

For example:

using StudentID = int;

StudentID studentNumber = 1025;

Now the variable's purpose is easier to recognize.

Remember: Type aliases provide alternative names for existing types, making code easier to understand.
