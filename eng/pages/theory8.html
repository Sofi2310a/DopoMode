08 — Arrays & Strings

Imagine you're writing a program that stores the scores of 100 players.

Creating 100 separate variables like score1, score2, score3... wouldn't be very practical, right?

In C++, arrays let you store multiple values of the same type in one collection, while strings let you work with text more easily.

Let's explore both!

1. What Are Arrays?

An array is a collection of elements of the same data type stored together in order.

Instead of creating five variables for five test scores, you can use one array.

int scores[5] = {90, 85, 78, 92, 88};

Here:

  • int is the data type of each element.
  • scores is the array's name.
  • [5] specifies that the array can hold 5 elements.
  • {90, 85, 78, 92, 88} provides the initial values.

Remember: All elements in a C++ array must have the same data type.

2. Accessing Array Elements

Each element in an array has an index, which is its position in the list.

In C++, array indexing starts at 0, not 1.

So for a 5-element array, the valid indexes are 0, 1, 2, 3, and 4.

#include <iostream>

int main() {
    int scores[5] = {90, 85, 78, 92, 88};

    std::cout << "First score: " << scores[0] << "\n";
    std::cout << "Second score: " << scores[1] << "\n";

    return 0;
}

Output:

First score: 90
Second score: 85

Changing an Element

You can update an array element using its index, just like a regular variable.

scores[1] = 95;
std::cout << "Updated second score: " << scores[1] << "\n";

Output:

Updated second score: 95

Now the second element contains 95 instead of 85.

Remember: The first element is always at index 0.

3. Arrays and Loops

Arrays and loops work together naturally because loops can visit each element one by one.

#include <iostream>

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};

    for (int i = 0; i < 5; i++) {
        std::cout << numbers[i] << " ";
    }

    return 0;
}

Output:

10 20 30 40 50

The loop variable i goes from 0 to 4, accessing numbers[0], numbers[1], numbers[2], numbers[3], and numbers[4].

Range-Based for Loop

C++ also provides a simpler loop syntax for going through elements in an array.

int numbers[5] = {10, 20, 30, 40, 50};

for (int n : numbers) {
    std::cout << n << " ";
}

Output:

10 20 30 40 50

This is called a range-based for loop. It automatically visits each element, making the code shorter and easier to read.

Remember: Loops make it easy to display, process, or update every element in an array efficiently.

4. Array Size and Common Mistakes

A built-in C++ array has a fixed size once created.

int numbers[3] = {5, 10, 15};

This array contains exactly three elements, with indexes 0, 1, and 2.

What happens if we try to access numbers[5]?

That goes out of bounds — reading or writing an element that doesn't exist! The program might display garbage values, crash, or behave unpredictably.

Important: Always stay within valid array indexes from 0 to size - 1. For collections that change size dynamically while a program runs, modern C++ also offers std::vector.

5. Multidimensional Arrays

Arrays can also have more than one dimension. A 2D array can be thought of as a table with rows and columns.

int grid[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

Here, grid has 2 rows and 3 columns.

  • Row 0 contains 1, 2, 3.
  • Row 1 contains 4, 5, 6.

The first index selects the row, and the second index selects the column. For example, grid[1][2] is 6.

Using Nested Loops

Nested loops are often used to go through all elements of a 2D array.

for (int row = 0; row < 2; row++) {
    for (int col = 0; col < 3; col++) {
        std::cout << grid[row][col] << " ";
    }
    std::cout << "\n";
}

Output:

1 2 3
4 5 6

Remember: 2D arrays are helpful for tables, game boards, and grids.

6. What Are Strings?

In C++, text is commonly stored using std::string from the <string> header.

#include <iostream>
#include <string>

int main() {
    std::string greeting = "Hello, C++!";
    std::cout << greeting << "\n";

    return 0;
}

Output:

Hello, C++!

char vs std::string

Remember char from the Data Types lesson?

  • char holds a single character, like 'A'.
  • std::string holds a sequence of characters, like "Apple" or a full sentence.

std::string is much more flexible than raw character arrays for everyday text handling.

Remember: Include <string> when using std::string.

7. Working with Strings

std::string makes common text operations straightforward.

Combining Strings

You can join strings together using the + operator.

std::string firstName = "Alex";
std::string lastName = "Smith";
std::string fullName = firstName + " " + lastName;

std::cout << fullName << "\n";

Output:

Alex Smith

Finding String Length

The length() function returns the number of elements in a string.

std::string text = "Hello";
std::cout << text.length() << "\n";

Output:

5

For ordinary English text, length() matches the number of characters. For text with accents, emojis, or multi-byte UTF-8 characters, note that length() counts bytes/code units rather than visual characters.

Accessing Characters

Just like an array, a string lets you access individual characters using indexes starting at 0.

std::string word = "Hello";
std::cout << word[0] << "\n";

Output:

H

You can also change a character by index:

std::string word = "Hello";
word[0] = 'J';
std::cout << word << "\n";

Output:

Jello

Be careful not to use an out-of-range index, which can cause undefined behavior.

Remember: Strings let you combine text, find its length, and access characters by index.

8. Reading Strings from the User

Using std::cin >> with a string stops reading at whitespace (such as a space, tab, or newline).

std::string firstName;
std::cout << "Enter your first name: ";
std::cin >> firstName;

What if the user enters a full name with spaces?

Reading an Entire Line

To read a full line including spaces, use std::getline(std::cin, variable).

#include <iostream>
#include <string>

int main() {
    std::string fullName;

    std::cout << "Enter your full name: ";
    std::getline(std::cin, fullName);

    std::cout << "Hello, " << fullName << "!\n";

    return 0;
}

Example Output:

Enter your full name: Alex Smith
Hello, Alex Smith!

Now the program can read multi-word input like Alex Smith without cutting it off at the first space.

Remember: Use std::getline when you want to read an entire line that may contain spaces.
