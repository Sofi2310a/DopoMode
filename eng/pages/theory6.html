06 — Loops

Imagine having to display the same message 100 times. Would you really want to write 100 separate lines of code?

That's exactly why we use loops. They let programs repeat actions automatically, saving time and making our programs easier to read.

In this lesson, you'll learn how to use three main types of loops in C++: for, while, and do-while.

1. What Are Loops?

A loop is a programming structure that repeats a block of code based on a condition.

Loops are commonly used for:

  • Counting up or down.
  • Processing information step by step.
  • Repeating tasks without duplicating code.

Each repetition of a loop is called an iteration.

Remember: A loop keeps repeating as long as its condition remains true.

2. The for Loop

The for loop is perfect when you know in advance how many times you want to repeat an action.

For example, let's display "Hello!" five times.

#include <iostream>

int main() {
    for (int i = 1; i <= 5; i++) {
        std::cout << "Hello!\n";
    }

    return 0;
}

Output:

Hello!
Hello!
Hello!
Hello!
Hello!

Instead of writing five output statements, we used just one!

How Does It Work?

A typical for loop has three parts:

for (initialization; condition; update) {
    // Code to repeat
}
  • Initialization — runs once before the loop begins.
  • Condition — is checked before each iteration. The loop continues while it's true.
  • Update — runs after each completed iteration of the loop body.

Let's trace the previous example:

  • int i = 1 sets a counter starting at 1.
  • i <= 5 allows the loop to continue while the counter is 5 or less.
  • i++ increases the counter by 1 after each run of the loop body.

Remember: Use for when you know the number of repetitions in advance.

3. The while Loop

The while loop repeats a block of code as long as a condition is true.

It's especially useful when we don't know exactly how many repetitions will be needed.

int number = 1;

while (number <= 5) {
    std::cout << number << "\n";
    number++;
}

Output:

1
2
3
4
5

How Does It Work?

  • The program checks whether number <= 5.
  • If the condition is true, it displays the number and increases it by one.
  • This repeats until number becomes 6. Then the condition becomes false, and the loop ends.

Important: A while loop checks its condition before running. If the condition is false from the beginning, the loop body may not run at all.

4. The do-while Loop

The do-while loop is similar to while, except it checks its condition after executing the loop body.

int number = 1;

do {
    std::cout << number << "\n";
    number++;
} while (number <= 5);

Output:

1
2
3
4
5

Now consider this example:

int number = 10;

do {
    std::cout << "This runs at least once!\n";
} while (number < 5);

Output:

This runs at least once!

This behaves differently from the previous example, and there's an important difference.

Even though the condition is false, the message still appears once.

That makes do-while useful for situations like showing a menu or asking for input before deciding whether to repeat.

Remember: do-while always executes its body at least once.

5. break and continue

Sometimes you need extra control inside a loop.

C++ provides two useful statements: break and continue.

break — Stop the Loop

break immediately exits the nearest enclosing loop.

for (int i = 1; i < 10; i++) {
    if (i == 5) {
        break;
    }
    std::cout << i << " ";
}

Output:

1 2 3 4

When i becomes 5, break triggers and the loop stops completely.

continue — Skip an Iteration

continue skips the remaining code in the current iteration and moves to the next one.

for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue;
    }
    std::cout << i << " ";
}

Output:

1 2 4 5

Here, the number 3 is skipped, but the loop continues.

Remember: break exits the loop early, while continue skips the remaining instructions in the current iteration.

6. Nested Loops

A nested loop is simply a loop inside another loop.

They're especially useful for creating tables, grids, and patterns.

Let's create a square made of stars.

for (int row = 1; row <= 3; row++) {
    for (int column = 1; column <= 3; column++) {
        std::cout << "* ";
    }
    std::cout << "\n";
}

Output:

* * *
* * *
* * *

Here's what's happening:

  • The outer loop controls the rows.
  • The inner loop prints three stars for each row.
  • After each row finishes, std::cout << "\n"; moves to the next line.

Each time the outer loop runs once, the inner loop completes all of its repetitions.

Remember: Nested loops run an inner loop inside an outer loop.

7. Infinite Loops

An infinite loop happens when a loop never stops because its stopping condition never becomes false.

Look at this example:

int number = 1;

while (number <= 5) {
    std::cout << number << "\n";
}

What's wrong?

The variable number never changes.

Since it always stays 1, the condition remains true, and the loop keeps printing the same number forever.

How Do We Fix It?

int number = 1;

while (number <= 5) {
    std::cout << number << "\n";
    number++;
}

Now number increases on each iteration, and the loop stops when number becomes 6.

Some programs intentionally use loops that run continuously, such as game loops or background services. However, these programs also need ways to exit or respond to shutdown requests.

Remember: Always understand how your loop will end, unless continuous execution is intentional.

8. Choosing the Right Loop

All three loops can repeat code, and each has its strengths.

Loop Used When For Example
for You know the number of repetitions in advance Printing numbers from 1 to 100
while You repeat while a condition is true before repeating Reading input until a valid value is entered
do-while The code must run at least once before checking the condition Showing a menu and asking whether to continue

There isn't always just one "perfect" loop for a task — choose the one that makes your logic clearest and easiest to understand.
