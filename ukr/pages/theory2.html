02 — Типи даних

Кожна програма працює з інформацією: числами, текстом, символами або простими відповідями «так/ні».

У цьому уроці ти дізнаєшся, як C++ зберігає різні типи інформації, як створювати змінні та як використовувати їх у програмах.

Наприкінці ти зможеш зберігати та змінювати значення, працювати з текстом і обирати правильний тип даних для різних завдань.

1. Що таке типи даних?

Уяви, що ти створюєш програму, яка зберігає інформацію про студента.

Тобі можуть знадобитися його ім’я, вік, зріст і те, чи він зараз навчається.

Ці значення різні, тому C++ використовує типи даних, щоб описати, яку саме інформацію містить кожна змінна.

Ось найпоширеніші типи:

Тип данихЩо зберігаєПриклад
intЦілі числа25
floatДесяткові числа3.14f
doubleТочніші десяткові числа3.14159
charОдин символ'A'
boolІстина або хибністьtrue
std::stringТекст"Hello"

Кожен тип має своє призначення. Правильний вибір допомагає програмі коректно працювати з інформацією.

Пам’ятай: тип даних повідомляє C++, з яким видом значення ти працюєш.

2. Змінні в C++

Змінна — це іменоване місце, де програма зберігає значення.

Уяви її як підписану коробку. Підпис — це ім’я змінної, а вміст — її значення.

Створімо одну:

int age = 18;

Ось що означає кожна частина:

  • int — тип даних.
  • age — ім’я змінної.
  • 18 — збережене значення.
  • ; — завершує інструкцію.

Ми можемо створювати змінні для різних видів інформації.

#include <iostream>
#include <string>

int main() {
    int age = 18;
    double height = 1.75;
    std::string name = "Alex";

    std::cout << "Name: " << name << "\n";
    std::cout << "Age: " << age << "\n";
    std::cout << "Height: " << height << "\n";

    return 0;
}

Вивід:

Name: Alex
Age: 18
Height: 1.75

Зміна значень змінних

Одна з найкорисніших речей у змінних — те, що ми можемо оновлювати їхні значення.

int score = 10;
score = 20;
std::cout << score;

Вивід:

20

Початкове значення 10 було замінене на 20.

Зверни увагу: ми пишемо int лише під час оголошення змінної, а не під час зміни її значення.

3. Цілі та десяткові числа

C++ надає кілька числових типів. Зосередьмося на трьох, які ти використовуватимеш найчастіше.

int — цілі числа

Використовуй int, коли потрібні числа без дробової частини.

int age = 20;
int temperature = -5;
int students = 30;

int може зберігати додатні числа, від’ємні числа та нуль.

Він корисний для віку, балів, лічильників та інших цілочисельних значень.

float — десяткові числа

Використовуй float для чисел, які можуть мати дробову частину.

float price = 19.99f;
float weight = 65.5f;

Літера f повідомляє C++, що це літерал типу float.

float зазвичай займає 4 байти та забезпечує точність близько 6–7 значущих десяткових цифр.

double — точніші числа

double також зберігає дробові значення, але зазвичай забезпечує більшу точність, ніж float.

double pi = 3.141592653589793;
double distance = 125.75;

double зазвичай займає 8 байтів і забезпечує точність близько 15–16 значущих десяткових цифр.

Для більшості загальних обчислень із дробовими значеннями double — хороший вибір за замовчуванням.

Одна важлива деталь: числа з плаваючою комою не можуть точно представити кожне десяткове значення, тому деякі обчислення можуть мати невеликі похибки округлення.

Пам’ятай: використовуй int для цілих чисел і double для більшості обчислень із дробовими значеннями.

4. Символи та рядки

Програми працюють не лише з числами. Їм також потрібно зберігати літери, імена та повідомлення.

char — один символ

Тип char зберігає один символ.

char grade = 'A';
char symbol = '#';
char digit = '5';

Символи записують в одинарних лапках.

Зверни увагу: '5' — це символ, а не ціле число 5.

std::string — текст

Коли потрібно зберегти слово або речення, використовуй std::string.

std::string name = "Alex";
std::string message = "Hello, C++!";

Рядки записують у подвійних лапках, і для них потрібен заголовок <string>.

Поєднаймо обидва типи в одній програмі.

#include <iostream>
#include <string>

int main() {
    char grade = 'A';
    std::string name = "Alex";

    std::cout << "Name: " << name << "\n";
    std::cout << "Grade: " << grade << "\n";

    return 0;
}

Вивід:

Name: Alex
Grade: A

Пам’ятай: char зберігає один символ, а std::string — текст різної довжини.

5. Логічний тип даних

Іноді програмі потрібно лише відповісти на запитання «так» або «ні».

Наприклад: студент онлайн? Гру завершено? Двері відчинені?

Для таких ситуацій C++ використовує тип bool.

Логічне значення може бути або true, або false.

bool isStudent = true;
bool hasLicense = false;

Виведімо логічне значення.

#include <iostream>

int main() {
    bool isOnline = true;

    std::cout << isOnline << "\n";

    return 0;
}

Вивід:

1

За замовчуванням std::cout виводить true як 1, а false як 0.

Щоб вивести самі слова, використовуй std::boolalpha:

std::cout << std::boolalpha << isOnline << "\n";

Вивід:

true

Логічні значення стають особливо корисними, коли ми починаємо писати програми, які ухвалюють рішення.

Пам’ятай: використовуй bool, коли інформація має два можливі стани: true або false.

6. Константи в C++

Не кожне значення має змінюватися.

Наприклад, у тижні завжди сім днів.

Ми можемо захистити значення від зміни за допомогою ключового слова const.

const int daysInWeek = 7;

Тепер, якщо ми спробуємо його змінити:

daysInWeek = 8;

Компілятор повідомить про помилку.

Константи корисні для значень, які мають залишатися незмінними протягом певної частини програми.

Вони також полегшують розуміння коду та зменшують ризик випадкових змін.

Пам’ятай: використовуй const, коли значення не повинно змінюватися після ініціалізації.

7. Іменування змінних

Хороші імена змінних роблять програми легшими для читання.

Порівняй ці два приклади:

int x = 18;
int studentAge = 18;

Обидва правильні, але другий чітко показує, що саме означає змінна.

Основні правила іменування

Імена змінних у C++:

  • Можуть містити літери, цифри та символи підкреслення.
  • Не можуть починатися з цифри.
  • Не можуть містити пробілів.
  • Не можуть використовувати зарезервовані ключові слова, як-от int або return.
  • Чутливі до регістру.

Правильні приклади:

int studentAge = 18;
int total_score = 100;
int number2 = 25;

Неправильні приклади:

int 2number = 10;
int student age = 18;
int return = 5;

У цьому курсі ми зазвичай використовуватимемо camelCase: перше слово починається з малої літери, а кожне наступне — з великої.

Наприклад: studentAge, totalScore, favoriteNumber

Пам’ятай: обирай імена, які пояснюють, що означають твої змінні.

8. Перетворення типів

Іноді потрібно змінити значення з одного типу даних на інший. Це називається перетворенням типів.

Є два поширені підходи.

Автоматичне перетворення

C++ може автоматично перетворювати деякі значення.

int number = 10;
double result = number;

std::cout << result;

Вивід:

10

Ціле значення було перетворене на double. Вивід усе ще показує 10, оскільки десяткова частина автоматично не відображається.

Явне перетворення

Ми також можемо самостійно запросити перетворення за допомогою static_cast.

double price = 19.99;
int wholePrice = static_cast<int>(price);

std::cout << wholePrice;

Вивід:

19

Дробову частину було відкинуто.

Так відбувається, тому що під час перетворення скінченного double на int дробова частина відкидається в бік нуля, якщо отримане ціле число входить у діапазон підтримуваних значень типу. Будь обережним: деякі перетворення можуть призвести до втрати інформації.

Пам’ятай: перетворення типів корисне, але зміна типів даних може вплинути на значення.

9. Підсумок уроку

  • Типи даних описують, який вид значення містить змінна.
  • Змінні зберігають значення, і їх можна оновлювати.
  • Використовуй int для цілих чисел і double для більшості дробових значень.
  • char зберігає один символ, std::string — текст.
  • bool зберігає true або false.
  • const захищає значення від змін.
  • Використовуй зрозумілі імена в стилі camelCase та будь уважним із перетворенням типів.
