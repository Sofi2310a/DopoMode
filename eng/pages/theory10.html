10 — Coding Practice

You've learned how to work with loops, functions, arrays, strings, and pointers. Now it's time to put those skills into action!

In this lesson, you'll complete 4 programming challenges, starting with simple calculations and moving toward more advanced tasks.

The goal isn't just to get the correct answer. It's to understand your code and learn how to solve problems independently.

1. Task 01 — Number Analyzer

Easy

Let's start by creating a program that analyzes five numbers entered by the user.

Your program should calculate their sum, find the largest number, and determine the average.

Requirements

  1. Create an array that stores 5 integers.
  2. Use a for loop to read the numbers.
  3. Calculate the sum of all elements.
  4. Find the largest number.
  5. Calculate the average using double.

Example Interaction

Enter 5 numbers:
10
25
5
40
20

Sum: 100
Largest number: 40
Average: 20

Hint

Use one variable to calculate the sum and another to track the largest number.

Start by setting the largest number to the first element of the array. This way, your program will also work when all entered numbers are negative.

When calculating the average, remember to use floating-point division so you don't lose the fractional part.

2. Task 02 — Text Analyzer

Easy

Now let's work with text!

Create a program that reads a sentence and counts its total number of characters and vowels.

Requirements

  1. Use std::string to store the sentence.
  2. Read the entire line using std::getline().
  3. Use a loop to examine each character.
  4. Count the vowels a, e, i, o, and u, including uppercase letters.
  5. Display both results.

Example Interaction

Enter a sentence: Hello World

Total characters: 11
Vowels: 3

Hint

Use .length() to get the string's length, then check each character with an if statement.

Don't forget that spaces count toward the total length!

For this exercise, use English text. With basic ASCII characters, the string's length matches the number of characters. Text containing some Unicode characters may require a different approach.

3. Task 03 — Function Calculator

Medium

Let's build a calculator!

Instead of placing every calculation inside main(), you'll organize the operations into separate functions.

Requirements

  1. Create four functions: add(), subtract(), multiply(), and divide().
  2. Each function must accept two double parameters and return a double.
  3. Display a menu with four mathematical operations.
  4. Use switch to select the operation.
  5. Prevent division by zero and handle an invalid menu choice.

Example Interaction

=== FUNCTION CALCULATOR ===

1. Addition
2. Subtraction
3. Multiplication
4. Division

Choose an operation: 3
Enter first number: 8
Enter second number: 6

Result: 48

Hint

Let main() handle user input and select the correct function.

Each calculation function should do only one job: calculate and return its result.

Before calling divide(), check whether the second number equals zero. If it does, display an error message instead of performing the division.

4. Task 04 — Pointer Challenge

Medium

Ready for a pointer challenge?

Create a program that swaps the values of two variables without returning either value from the function.

You'll do this by working directly with their memory addresses.

Requirements

  1. Create two integer variables.
  2. Ask the user to enter their values.
  3. Create a function named swapNumbers().
  4. Pass the addresses of both variables to the function.
  5. Use pointers to exchange the values.
  6. Display the values before and after swapping.

Example Interaction

Enter first number: 10
Enter second number: 25

Before swapping:
First: 10
Second: 25

After swapping:
First: 25
Second: 10

Hint

void swapNumbers(int* a, int* b) {
    // Swap the values here.
}

You'll need a temporary variable to store one of the original values.

Remember that *a and *b let you access the actual integers through their pointers.
