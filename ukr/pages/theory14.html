14 — STL & Files

1. What Is STL?

The Standard Template Library (STL) is a collection of ready-to-use tools for storing, organizing, and processing data in C++.

Instead of creating every data structure or algorithm yourself, you can use existing components from the C++ standard library.

The STL includes three important parts:

  • Containers — store collections of data.
  • Algorithms — perform operations such as sorting and searching.
  • Iterators — provide a way to access elements inside containers.

Using STL makes code shorter, easier to maintain, and more efficient.

Key Point: STL provides reusable tools that help programmers work with data without writing everything from scratch.

2. Vectors

A vector is a dynamic array that can automatically grow or shrink as elements are added or removed.

Unlike regular arrays, vectors do not require you to specify a fixed number of elements.

To use vectors, include the <vector> header.

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> numbers = {10, 20, 30};

    numbers.push_back(40);

    for (int number : numbers) {
        cout << number << " ";
    }

    return 0;
}

Output:

10 20 30 40

Common Vector Operations

Operation Description
push_back() Adds an element to the end
pop_back() Removes the last element
size() Returns the number of elements
empty() Checks whether the vector is empty
at() Accesses an element with bounds checking
clear() Removes all elements

Example:

vector<int> scores = {80, 90, 100};

cout << scores.at(0) << endl;
cout << scores.size();

Output:

80
3

Remember: Use vector when you need a collection of elements whose size may change.

3. Other STL Containers

C++ provides different containers for different purposes.

array — Fixed-Size Collection

The std::array container stores a fixed number of elements.

#include <array>

array<int, 3> numbers = {10, 20, 30};

Unlike a traditional C-style array, std::array provides useful functions such as .size() and .at().

map — Key-Value Pairs

A map stores information as pairs of keys and values.

For example, we can store student names and their scores.

#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<string, int> scores;

    scores["Alex"] = 90;
    scores["Emma"] = 95;

    cout << scores["Emma"];

    return 0;
}

Output:

95

Each key in a map is unique, and its elements are ordered by key.

set — Unique Values

A set stores unique values in sorted order.

#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> numbers = {5, 2, 5, 1};

    for (int number : numbers) {
        cout << number << " ";
    }

    return 0;
}

Output:

1 2 5

The repeated value 5 is stored only once.

Key Point: Choose containers based on how you need to organize and access your data.

Practice Exercise

Create a map that stores the scores of two students and a set containing {4, 2, 4, 1}. Print a student's score and the unique set elements.

4. STL Algorithms

Algorithms are ready-made functions that perform common operations on collections of data.

The <algorithm> header provides many useful functions.

Some of the most common are:

Algorithm Description
sort() Sorts elements
find() Searches for a value
reverse() Reverses the order of elements
count() Counts occurrences of a value
max_element() Finds the largest element
min_element() Finds the smallest element

Sorting a Vector

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> numbers = {5, 2, 8, 1, 3};

    sort(numbers.begin(), numbers.end());

    for (int number : numbers) {
        cout << number << " ";
    }

    return 0;
}

Output:

1 2 3 5 8

The sort() function arranges the numbers in ascending order.

Finding an Element

vector<int> numbers = {10, 20, 30};

auto result = find(numbers.begin(), numbers.end(), 20);

if (result != numbers.end()) {
    cout << "Number found!";
}

Output:

Number found!

The find() function returns an iterator to the matching element. If the value is not found, it returns the end iterator.

Remember: STL algorithms allow you to perform common operations without manually writing complex loops.

Practice Exercise

Create a vector containing {9, 3, 7, 3, 1}. Sort it, then use count() to determine how many times 3 appears.

5. Iterators

An iterator is an object used to access elements in a container.

Iterators work similarly to pointers, allowing us to move through collections.

Example:

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> numbers = {10, 20, 30};

    for (auto it = numbers.begin(); it != numbers.end(); ++it) {
        cout << *it << " ";
    }

    return 0;
}

Output:

10 20 30

Here:

  • begin() — returns an iterator to the first element.
  • end() — returns an iterator representing the position after the last element.
  • ++it — moves to the next element.
  • *it — accesses the current element.

Important: The iterator returned by end() must not be dereferenced.

Iterators are especially useful when working with STL algorithms.

Key Point: Iterators provide a common way to access elements in different containers.

Practice Exercise

6. What Is File Handling?

Normally, information stored in variables disappears when a program finishes.

File handling allows programs to save information and read it again later.

For example, a program can store student grades, user settings, or game progress in a file.

C++ provides the <fstream> header for working with files.

Three common file stream types are:

Type Purpose
ofstream Writes data to a file
ifstream Reads data from a file
fstream Supports reading and writing

Key Point: Files allow programs to keep information even after they stop running.

File Paths: Relative and Absolute

A relative path such as "notes.txt" is resolved from the program's current working directory, not necessarily from the folder containing main.cpp or the executable. An absolute path explicitly identifies a location, but its syntax depends on the operating system. You can inspect the current working directory with std::filesystem::current_path() (include <filesystem>, C++17 or newer). Always make sure the target directory exists and the program has permission to access it.

#include <iostream>
#include <filesystem>

int main() {
    std::cout << std::filesystem::current_path() << "\n";
}

Understanding Stream States

A file stream tracks whether operations succeeded. is_open() tells you whether a file is open. The stream can be tested with if (file) to check whether it is currently in a good state; fail() detects a failed operation, bad() reports a serious I/O error, and eof() indicates an end-of-file condition has been reached. After reading with while (getline(file, line)), reaching the end normally causes the loop to stop; check bad() if you need to distinguish a serious read error from a normal end-of-file.

7. Writing to a File

To write information into a file, we use ofstream.

Example:

#include <iostream>
#include <fstream>
using namespace std;

int main() {
    ofstream file("notes.txt");

    if (file.is_open()) {
        file << "Hello, C++!" << endl;
        file << "Learning file handling.";

        file.close();
        cout << "File saved!";
    } else {
        cout << "Cannot open file!";
    }

    return 0;
}

Console Output:

File saved!

File Content — notes.txt:

Hello, C++!
Learning file handling.

How Does It Work?

  • ofstream file("notes.txt") — opens a file for writing.
  • is_open() — checks whether the file was opened successfully.
  • file << — writes information into the file.
  • close() — closes the file.

By default, opening an existing file with ofstream in this way replaces its previous contents.

Remember: Use ofstream to save information into files.

Checking Write Success

#include <fstream>
#include <iostream>

int main() {
    std::ofstream file("notes.txt");
    if (!file.is_open()) {
        std::cerr << "Cannot open file!\n";
        return 1;
    }

    file << "Hello, C++!\n";
    file.close();

    if (!file) {
        std::cerr << "Could not finish writing.\n";
        return 1;
    }

    std::cout << "File saved!\n";
}

Check not only that the file opened, but also that the writing and closing completed successfully. Closing a stream can reveal buffered write errors that were not visible earlier.

8. Reading from a File

To read information from an existing file, we use ifstream.

Example:

#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main() {
    ifstream file("notes.txt");
    string line;

    if (file.is_open()) {
        while (getline(file, line)) {
            cout << line << endl;
        }

        file.close();
    } else {
        cout << "Cannot open file!";
    }

    return 0;
}

If notes.txt contains the text from the previous example, the output will be:

Hello, C++!
Learning file handling.

The getline() function reads one complete line at a time.

The while loop continues until there are no more lines to read.

Key Point: Use ifstream to retrieve information stored in files.

The relative filename is interpreted using the current working directory. If the file isn't found, check that directory and the filename. After the reading loop, file.bad() can help identify serious input errors. A normal end-of-file is expected and does not necessarily indicate a problem.

9. Appending Data to a File

Sometimes we want to add new information without deleting what is already stored.

This is called appending.

To append data, use ios::app.

#include <iostream>
#include <fstream>
using namespace std;

int main() {
    ofstream file("notes.txt", ios::app);

    if (file.is_open()) {
        file << "\nNew information added.";
        file.close();

        cout << "Text added!";
    } else {
        cout << "Cannot open file!";
    }

    return 0;
}

Output:

Text added!

If the file already contains:

Hello, C++!

After running the program, its content becomes:

Hello, C++!
New information added.

Remember: Use ios::app when you want to add data to the end of a file without replacing its existing contents.

Practice Exercise

10. Common File Handling Mistakes

Working with files requires a few important precautions.

1. Assuming a file always exists

A file may not exist or may not be accessible. Always check whether opening it was successful.

2. Using the wrong file path

A relative path such as "notes.txt" is normally resolved relative to the program's current working directory, which may differ from the folder containing your source code.

3. Accidentally overwriting data

Opening a file with ofstream normally replaces its existing contents unless an appropriate mode, such as ios::app, is used.

4. Ignoring write errors

Successfully opening a file does not guarantee that every write operation succeeds. For important data, check the stream state after writing.

5. Forgetting to close files

File streams close automatically when their objects are destroyed, but calling close() explicitly can be useful when you need to finish working with a file before the program ends.

Key Point: Always handle file operations carefully to avoid losing important information.
