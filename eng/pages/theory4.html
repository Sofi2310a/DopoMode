04 — Conditions

What if your program could make decisions?

Imagine a game that checks whether a player has enough points to unlock a new level, or an application that verifies a user's age.

In C++, conditions allow programs to choose different actions based on whether something is true or false.

Let's learn how they work!

1. The if Statement

The if statement runs a block of code only when a condition is true.

For example, let's check whether someone is old enough to enter an event.

#include <iostream>

int main() {
    int age = 20;

    if (age >= 18) {
        std::cout << "Access granted!\n";
    }

    return 0;
}

Output:

Access granted!

The program checks whether age is at least 18.

If the condition is true, the message appears. Otherwise, the code inside the braces is skipped.

Remember: if executes code only when its condition is true.

2. The if-else Statement

Sometimes we need to choose between two possible actions.

That's where else comes in.

int temperature = 15;

if (temperature >= 20) {
    std::cout << "It is warm!\n";
} else {
    std::cout << "It is cold!\n";
}

Output:

It is cold!

Since the temperature is below 20, the program executes the else block.

Remember: if handles the true case, while else handles the alternative.

3. The else-if Statement

What if there are more than two possible outcomes?

We can use else if to check additional conditions.

int score = 85;

if (score >= 90) {
    std::cout << "Excellent!\n";
} else if (score >= 70) {
    std::cout << "Good!\n";
} else if (score >= 50) {
    std::cout << "Passed!\n";
} else {
    std::cout << "Failed!\n";
}

Output:

Good!

C++ checks the conditions from top to bottom.

As soon as it finds a true condition, it executes that block and skips the remaining branches.

Remember: else if helps you choose between several possible outcomes.

4. Combining Conditions

Sometimes one condition isn't enough.

Imagine a concert where visitors must be at least 18 years old and have a ticket.

We can combine conditions using logical operators.

OperatorNameMeaning
&&ANDBoth conditions must be true
||ORAt least one condition must be true
!NOTReverses a Boolean value

Let's try an example:

int age = 20;
bool hasTicket = true;

if (age >= 18 && hasTicket) {
    std::cout << "Access granted!\n";
} else {
    std::cout << "Access denied!\n";
}

Output:

Access granted!

Both conditions are true so access is granted.

These operators make it possible to create more specific rules for your programs.

5. The switch Statement

When we need to check one value against several fixed options, switch can be a convenient alternative to multiple else if statements.

For example, let's display a day of the week.

int day = 2;

switch (day) {
    case 1:
        std::cout << "Monday\n";
        break;
    case 2:
        std::cout << "Tuesday\n";
        break;
    case 3:
        std::cout << "Wednesday\n";
        break;
    default:
        std::cout << "Unknown day\n";
}

Output:

Tuesday

Here's how it works:

  • switch checks the value.
  • case defines a possible match.
  • break exits the switch.
  • default handles values that don't match any case.

Without break, execution may continue into the next case.

Important: A regular C++ switch works with integer, character, and enumeration values, but not directly with std::string.

6. The Ternary Operator

C++ offers a shorter way to choose between two values using the ternary operator ?:.

Its structure is: condition ? valueIfTrue : valueIfFalse

Let's see an example:

int age = 20;

std::string result = (age >= 18) ? "Adult" : "Minor";

std::cout << result << "\n";

Output:

Adult

If the condition is true, the first value is selected. Otherwise, the second value is selected.

It's useful for simple decisions, but if-else is usually clearer for more complex logic.

7. Nested Conditions

Sometimes one decision depends on another.

For example, a visitor must be an adult before we check whether they have an ID.

int age = 20;
bool hasID = true;

if (age >= 18) {
    if (hasID) {
        std::cout << "Entry allowed!\n";
    } else {
        std::cout << "ID required!\n";
    }
} else {
    std::cout << "You are too young!\n";
}

Output:

Entry allowed!

First, the program checks the age. If the visitor is old enough, it checks for an ID.

This is called a nested condition .

Nested condition are useful, but too many levels can make your code harder to read.
