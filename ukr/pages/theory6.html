06 — Цикли

Уяви, що потрібно вивести те саме повідомлення 100 разів. Невже ти справді хотів би писати 100 окремих рядків коду?

Саме тому ми використовуємо цикли. Вони дозволяють програмам автоматично повторювати дії, заощаджуючи час і роблячи програми легшими для читання.

У цьому уроці ти навчишся використовувати три основні типи циклів у C++: for, while і do-while.

1. Що таке цикли?

Цикл — це програмна структура, яка повторює блок коду залежно від умови.

Цикли зазвичай використовують для:

  • Рахунку вгору чи вниз.
  • Покрокової обробки інформації.
  • Повторення завдань без дублювання коду.

Кожне повторення циклу називається ітерацією.

Пам’ятай: цикл повторюється доти, доки його умова залишається істинною.

2. Цикл for

Цикл for ідеально підходить, коли ти заздалегідь знаєш, скільки разів потрібно повторити дію.

Наприклад, виведімо «Hello!» п’ять разів.

#include <iostream>

int main() {
    for (int i = 1; i <= 5; i++) {
        std::cout << "Hello!\n";
    }

    return 0;
}

Вивід:

Hello!
Hello!
Hello!
Hello!
Hello!

Замість того щоб писати п’ять інструкцій виводу, ми використали лише одну!

Як це працює?

Типовий цикл for має три частини:

for (initialization; condition; update) {
    // Код, що повторюється
}
  • Ініціалізація — виконується один раз перед початком циклу.
  • Умова — перевіряється перед кожною ітерацією. Цикл продовжується, поки вона істинна.
  • Оновлення — виконується після кожної завершеної ітерації тіла циклу.

Розберімо попередній приклад:

  • int i = 1 задає лічильник, що починається з 1.
  • i <= 5 дозволяє циклу продовжуватися, поки лічильник не перевищує 5.
  • i++ збільшує лічильник на 1 після кожного виконання тіла циклу.

Пам’ятай: використовуй for, коли заздалегідь знаєш кількість повторень.

3. Цикл while

Цикл while повторює блок коду, доки умова істинна.

Він особливо корисний, коли ми точно не знаємо, скільки повторень знадобиться.

int number = 1;

while (number <= 5) {
    std::cout << number << "\n";
    number++;
}

Вивід:

1
2
3
4
5

Як це працює?

  • Програма перевіряє, чи number <= 5.
  • Якщо умова істинна, вона виводить число та збільшує його на одиницю.
  • Це повторюється, доки number не стане 6. Тоді умова стає хибною, і цикл завершується.

Важливо: цикл while перевіряє свою умову перед виконанням. Якщо умова з самого початку хибна, тіло циклу може не виконатися жодного разу.

4. Цикл do-while

Цикл do-while схожий на while, але перевіряє свою умову після виконання тіла циклу.

int number = 1;

do {
    std::cout << number << "\n";
    number++;
} while (number <= 5);

Вивід:

1
2
3
4
5

Тепер розглянь такий приклад:

int number = 10;

do {
    std::cout << "This runs at least once!\n";
} while (number < 5);

Вивід:

This runs at least once!

Він поводиться інакше, ніж попередній приклад, і ця різниця важлива.

Хоча умова хибна, повідомлення все одно з’являється один раз.

Це робить do-while корисним у ситуаціях, як-от показ меню чи запит вводу перед тим, як вирішити, чи повторювати.

Пам’ятай: do-while завжди виконує своє тіло принаймні один раз.

5. break і continue

Іноді потрібен додатковий контроль усередині циклу.

C++ надає дві корисні інструкції: break і continue.

break — зупинити цикл

break негайно виходить із найближчого циклу, що його охоплює.

for (int i = 1; i < 10; i++) {
    if (i == 5) {
        break;
    }
    std::cout << i << " ";
}

Вивід:

1 2 3 4

Коли i стає 5, спрацьовує break, і цикл повністю зупиняється.

continue — пропустити ітерацію

continue пропускає решту коду в поточній ітерації та переходить до наступної.

for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue;
    }
    std::cout << i << " ";
}

Вивід:

1 2 4 5

Тут число 3 пропускається, але цикл продовжується.

Пам’ятай: break достроково виходить із циклу, а continue пропускає решту інструкцій у поточній ітерації.

6. Вкладені цикли

Вкладений цикл — це просто цикл усередині іншого циклу.

Вони особливо корисні для створення таблиць, сіток і візерунків.

Створімо квадрат із зірочок.

for (int row = 1; row <= 3; row++) {
    for (int column = 1; column <= 3; column++) {
        std::cout << "* ";
    }
    std::cout << "\n";
}

Вивід:

* * *
* * *
* * *

Ось що відбувається:

  • Зовнішній цикл керує рядками.
  • Внутрішній цикл виводить три зірочки для кожного рядка.
  • Після завершення кожного рядка std::cout << "\n"; переходить на наступний рядок.

Щоразу, коли зовнішній цикл виконується один раз, внутрішній цикл виконує всі свої повторення.

Пам’ятай: вкладені цикли запускають внутрішній цикл усередині зовнішнього.

7. Нескінченні цикли

Нескінченний цикл виникає, коли цикл ніколи не зупиняється, тому що його умова завершення ніколи не стає хибною.

Подивись на цей приклад:

int number = 1;

while (number <= 5) {
    std::cout << number << "\n";
}

У чому проблема?

Змінна number ніколи не змінюється.

Оскільки вона завжди дорівнює 1, умова залишається істинною, і цикл нескінченно виводить те саме число.

Як це виправити?

int number = 1;

while (number <= 5) {
    std::cout << number << "\n";
    number++;
}

Тепер number збільшується під час кожної ітерації, і цикл зупиняється, коли number стає 6.

Деякі програми навмисно використовують цикли, що працюють безперервно, наприклад ігрові цикли або фонові служби. Проте таким програмам також потрібні способи виходу або реакції на запити про завершення роботи.

Пам’ятай: завжди розумій, як завершиться твій цикл, якщо тільки безперервне виконання не є навмисним.

8. Вибір правильного циклу

Усі три цикли можуть повторювати код, і кожен має свої сильні сторони.

Цикл Коли використовувати Приклад
for Ти заздалегідь знаєш кількість повторень Виведення чисел від 1 до 100
while Ти повторюєш, доки умова істинна, причому перевіряєш її перед повторенням Читання вводу, доки не буде введено коректне значення
do-while Код має виконатися принаймні один раз до перевірки умови Показ меню та запит, чи продовжувати

Не завжди існує лише один «ідеальний» цикл для завдання — обирай той, який робить твою логіку найчіткішою та найзрозумілішою.
