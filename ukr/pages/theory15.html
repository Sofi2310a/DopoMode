15 — Фінальний проєкт

Вітаємо! Ти дійшов до фінального проєкту курсу C++!

Ти вже навчився працювати зі змінними, умовами, циклами, функціями, масивами, вказівниками, класами, контейнерами та файлами.

Тепер настав час об’єднати всі ці знання та створити справжній застосунок.

Твоє завдання — розробити систему керування студентами (Student Management System). Це консольний застосунок, який дозволяє додавати, переглядати, шукати, оновлювати та видаляти записи про студентів.

Цей проєкт допоможе тобі зрозуміти, як різні можливості C++ працюють разом у повноцінній програмі.

1. Огляд проєкту

Середній рівень

Фінальний проєкт

Назва проєкту: Система керування студентами.

Твій застосунок керуватиме інформацією про студентів через просте текстове меню.

Кожен студент повинен мати чотири характеристики:

  • ID — унікальний номер, який ідентифікує студента.
  • Ім’я — повне ім’я студента.
  • Вік — вік студента.
  • Оцінка — середній бал студента.

Застосунок також повинен зберігати записи про студентів у файл, щоб вони залишалися доступними після завершення роботи програми.

Приклад меню

===== КЕРУВАННЯ СТУДЕНТАМИ =====

1. Додати студента
2. Переглянути студентів
3. Знайти студента
4. Оновити дані студента
5. Видалити студента
6. Зберегти студентів
0. Вихід

Виберіть пункт меню:

Меню повинно з’являтися знову після кожної операції, доки користувач не вибере 0 для виходу.

Замість того щоб писати всю програму одразу, ми створюватимемо її крок за кроком.

2. Крок 01 — Створення класу Student

Почнімо з визначення того, як студент буде представлений у нашій програмі.

Ми використаємо клас, щоб об’єднати пов’язані дані та поведінку.

#include <iostream>
#include <string>
#include <vector>
#include <fstream>
#include <limits>

class Student {
public:
    int id;
    std::string name;
    int age;
    double grade;

    Student(int i, std::string n, int a, double g)
        : id(i), name(n), age(a), grade(g) {
    }

    void display() const {
        std::cout << "ID: " << id << "\n";
        std::cout << "Name: " << name << "\n";
        std::cout << "Age: " << age << "\n";
        std::cout << "Grade: " << grade << "\n";
    }
};

Як це працює?

Клас Student містить чотири поля та функцію-член display().

Конструктор ініціалізує об’єкт студента інформацією, яку ми передаємо під час його створення.

Наприклад:

Student student1(1, "Alex", 18, 95.5);

student1.display();

Вивід:

ID: 1
Name: Alex
Age: 18
Grade: 95.5

Для простоти в цьому прикладі використано публічні поля. У більших застосунках приватні поля та контрольований доступ до них допомагають краще захищати дані.

Пам’ятай: класи дозволяють об’єднувати пов’язані дані та поведінку в об’єкти, які можна повторно використовувати.

3. Крок 02 — Зберігання студентів у векторі

У закладі освіти може навчатися багато студентів, і ми не знаємо заздалегідь, скільки записів знадобиться нашому застосунку.

Саме тому використаємо std::vector.

На відміну від звичайних масивів фіксованого розміру, вектори можуть збільшуватися під час додавання нових елементів.

std::vector<Student> students;

Щоб додати студента:

students.emplace_back(1, "Alex", 18, 95.5);

Тепер створімо функцію, яка відображатиме всіх студентів.

void viewStudents(const std::vector<Student>& students) {
    if (students.empty()) {
        std::cout << "No students found.\n";
        return;
    }

    for (const Student& student : students) {
        student.display();
        std::cout << "----------\n";
    }
}

Цикл for на основі діапазону перебирає всіх студентів у векторі.

Ми використовуємо const Student&, щоб отримувати доступ до об’єктів без створення зайвих копій.

Твоє завдання

Створи функцію addStudent(), яка:

  1. Запитує у користувача ID, ім’я, вік та оцінку студента.
  2. Перевіряє, чи не використовується вже введений ID.
  3. Перевіряє правильність введених даних.
  4. Додає нового студента до вектора.

Важливо: кожен студент повинен мати унікальний ID.

4. Крок 03 — Пошук студентів

Тепер додаймо можливість пошуку.

Уяви, що в системі зберігаються дані про 100 студентів. Шукати одного з них вручну було б незручно.

Натомість ми створимо функцію, яка шукатиме студента за його ID.

Student* findStudent(std::vector<Student>& students, int id) {
    for (Student& student : students) {
        if (student.id == id) {
            return &student;
        }
    }

    return nullptr;
}

Як це працює?

Функція послідовно перевіряє студентів, доки не знайде запис із відповідним ID.

Якщо збіг знайдено, вона повертає вказівник на цього студента.

Якщо студента не знайдено, функція повертає nullptr.

Ось як її використовувати:

Student* result = findStudent(students, 1);

if (result != nullptr) {
    result->display();
} else {
    std::cout << "Student not found.\n";
}

Важливо: вказівники на елементи вектора можуть стати недійсними після зміни вектора. Використовуй отриманий результат одразу й не зберігай його після операцій, які можуть зробити вказівник недійсним.

Твоє завдання

Додай пункт меню, який запитуватиме ID студента та відображатиме його інформацію, якщо відповідний запис знайдено.

5. Крок 04 — Оновлення та видалення студентів

Наш застосунок уже може зберігати інформацію про студентів і знаходити потрібні записи.

Тепер дозволимо користувачам редагувати та видаляти дані.

Оновлення даних студента

Створи функцію updateStudent(), яка:

  1. Запитує ID студента.
  2. Знаходить відповідного студента.
  3. Виводить повідомлення, якщо студента не знайдено.
  4. Запитує нове ім’я, вік та оцінку.
  5. Перевіряє нові дані та оновлює наявний запис.

Для пошуку потрібного студента можна повторно використати функцію findStudent().

Видалення студента

Щоб видалити студента, скористаємося функцією erase() контейнера vector.

void deleteStudent(std::vector<Student>& students, int id) {
    for (auto it = students.begin();
         it != students.end(); ++it) {

        if (it->id == id) {
            students.erase(it);
            std::cout << "Student deleted!\n";
            return;
        }
    }

    std::cout << "Student not found.\n";
}

Функція шукає запис із відповідним ID та видаляє його з вектора.

Після виклику erase() раніше збережені ітератори та вказівники на видалений і наступні за ним елементи стають недійсними.

Що таке CRUD?

Ці чотири операції мають спільну назву в розробці програмного забезпечення:

Операція Значення
Create — створення Додавання нового запису
Read — читання Перегляд або пошук запису
Update — оновлення Зміна наявного запису
Delete — видалення Видалення запису

Разом ці операції називаються CRUD.

Ти зустрінеш їх під час роботи з базами даних, вебсайтами та багатьма реальними застосунками.

6. Крок 05 — Збереження студентів у файл

Поки що наш застосунок має одну важливу проблему.

Коли програма завершує роботу, записи про студентів, які зберігалися в оперативній пам’яті, зникають.

Щоб зберегти їх, нам знадобиться робота з файлами.

Збережімо дані студентів у текстовий файл.

void saveStudents(const std::vector<Student>& students) {
    std::ofstream file("students.txt");

    if (!file.is_open()) {
        std::cout << "Cannot open file!\n";
        return;
    }

    for (const Student& student : students) {
        file << student.id << "\n";
        file << student.name << "\n";
        file << student.age << "\n";
        file << student.grade << "\n";
    }

    file.close();

    if (file) {
        std::cout << "Students saved!\n";
    } else {
        std::cout << "Error saving students!\n";
    }
}

Приклад вмісту файлу

1
Alex
18
95.5
2
Emma
19
92

Інформація про кожного студента займає чотири рядки у файлі.

Перший рядок містить ID, наступні — ім’я, вік та оцінку.

Відкриття наявного файлу через std::ofstream у такий спосіб зазвичай замінює його попередній вміст. Тому застосунок повинен чітко повідомляти про помилки збереження.

Твоє завдання

Створи функцію loadStudents(), яка:

  1. Відкриває файл students.txt під час запуску програми.
  2. Зчитує чотири поля для кожного студента.
  3. Створює об’єкт Student для кожного коректного запису.
  4. Додає студента до вектора.
  5. Обробляє відсутні файли, неповні записи, некоректні значення та повторювані ID.

У межах цього проєкту зберігай ім’я студента в одному рядку без символів переходу на новий рядок. Для запису та читання оцінок використовуй узгоджений числовий формат і локаль.

Пам’ятай: збереження даних дозволяє застосунку зберігати інформацію між запусками.

7. Крок 06 — Створення головного меню

Тепер настав час об’єднати всі частини в один застосунок.

Ми використаємо цикл do-while, щоб меню продовжувало працювати, а оператор switch — для обробки вибору користувача.

Наступний приклад — це початковий шаблон. Він передбачає, що клас Student і наведені раніше функції вже визначені.

int main() {
    std::vector<Student> students;
    int choice = -1;

    do {
        std::cout << "\n===== STUDENT MANAGEMENT =====\n";
        std::cout << "1. Add Student\n";
        std::cout << "2. View Students\n";
        std::cout << "3. Search Student\n";
        std::cout << "4. Update Student\n";
        std::cout << "5. Delete Student\n";
        std::cout << "6. Save Students\n";
        std::cout << "0. Exit\n";
        std::cout << "Choose an option: ";

        if (!(std::cin >> choice)) {
            if (std::cin.eof()) {
                std::cout << "\nInput ended.\n";
                break;
            }

            std::cout << "Invalid input!\n";
            std::cin.clear();
            std::cin.ignore(
                std::numeric_limits<std::streamsize>::max(),
                '\n'
            );
            continue;
        }

        std::cin.ignore(
            std::numeric_limits<std::streamsize>::max(),
            '\n'
        );

        switch (choice) {
            case 1:
                std::cout << "Add Student selected\n";
                break;

            case 2:
                viewStudents(students);
                break;

            case 3:
                std::cout << "Search Student selected\n";
                break;

            case 4:
                std::cout << "Update Student selected\n";
                break;

            case 5:
                std::cout << "Delete Student selected\n";
                break;

            case 6:
                saveStudents(students);
                break;

            case 0:
                std::cout << "Goodbye!\n";
                break;

            default:
                std::cout << "Invalid option!\n";
        }

    } while (choice != 0);

    return 0;
}

Твоє завдання

Заміни тимчасові повідомлення викликами створених тобою функцій.

Також переконайся, що програма:

  • Завантажує збережені записи під час запуску.
  • Коректно обробляє неправильне введення та не зависає.
  • Повторно відображає меню після кожної операції.
  • Зберігає записи, коли користувач вибирає пункт 6.

Додаткове завдання: реалізуй автоматичне збереження змін перед завершенням програми.

9. Тестування застосунку

Якщо програма успішно компілюється, це ще не означає, що в ній немає помилок.

Перш ніж вважати проєкт завершеним, перевір різні сценарії роботи.

Тест Очікуваний результат
Додати студента Студент з’являється у списку
Додати студента з повторюваним ID Запис відхиляється
Знайти наявний ID Відображається інформація про студента
Знайти невідомий ID З’являється зрозуміле повідомлення
Оновити дані студента Відображається оновлена інформація
Видалити студента Запис зникає зі списку
Зберегти дані та перезапустити програму Раніше збережені записи відновлюються
Ввести некоректні дані Програма безпечно обробляє помилку
Завантажити пошкоджений файл Некоректні записи обробляються без аварійного завершення програми

Особливу увагу приділи неочікуваним даним: літерам замість чисел, від’ємному віку, некоректним оцінкам і неповним файлам.

Пам’ятай: тестування — це частина програмування, а не лише останній крок після написання коду.
