12 — Classes & Objects

Imagine creating a game with dozens of characters. Each character has a name, health points, and special abilities.

Instead of managing all this information separately, wouldn't it be easier to keep everything together?

That's exactly what classes and objects allow us to do!

In this lesson, you'll discover the basics of Object-Oriented Programming (OOP) and learn how to create your own classes in C++.

1. What Is Object-Oriented Programming?

Object-Oriented Programming (OOP) is an approach to programming that organizes code around objects.

An object can combine two important things:

  • Data — information such as a player's name or health.
  • Behavior — actions such as attacking, healing, or displaying information.

OOP helps developers organize large programs, reuse code, and control access to important data.

Think of a class as a blueprint for creating objects. Let's see how that works!

2. What Are Classes?

A class is a custom data type that defines what information an object contains and what actions it can perform.

Let's create a simple Student class.

#include <iostream>
#include <string>

class Student {
public:
    std::string name;
    int age;

    void introduce() {
        std::cout << "Hi, I'm " << name << "!\n";
    }
};

How Does It Work?

  • class Student — defines a class named Student.
  • name and age — are data members that store information.
  • introduce() — is a member function that performs an action.
  • public: — allows these members to be accessed from outside the class.

A function that belongs to a class is called a member function, often referred to as a method.

Notice the semicolon after the closing brace. C++ requires it at the end of a class definition.

3. Creating Objects

An object is an instance of a class.

Once we've defined a class, we can create as many objects as we need.

#include <iostream>
#include <string>

class Student {
public:
    std::string name;
    int age;

    void introduce() {
        std::cout << "Hi, I'm " << name << "!\n";
    }
};

int main() {
    Student student1{};
    Student student2{};

    student1.name = "Alex";
    student1.age = 18;

    student2.name = "Emma";
    student2.age = 19;

    student1.introduce();
    student2.introduce();

    return 0;
}

Output:

Hi, I'm Alex!
Hi, I'm Emma!

Both objects come from the same class, but each stores its own information.

We use the dot operator (.) to access public data members and call member functions.

Remember: One class can create many objects, each with its own data.

4. Access Modifiers

Not every part of an object should be accessible from anywhere in a program.

C++ provides access specifiers to control which members can be accessed.

Access Specifier Meaning
public Accessible from outside the class
private Accessible within the class and by its friends
protected Accessible within the class, by its friends, and in derived classes

Let's look at an example:

#include <iostream>

class BankAccount {
private:
    double balance = 1000.0;

public:
    void showBalance() const {
        std::cout << balance << "\n";
    }
};

int main() {
    BankAccount account;

    account.showBalance();

    return 0;
}

Output:

1000

The balance member is private, so we cannot access it directly from main().

However, the public function showBalance() can read it.

The const after the function's parentheses indicates that this member function won't modify the object's non-mutable data members.

Remember: Members of a class are private by default. Use public to expose the operations other parts of your program need.

5. Encapsulation

Imagine a banking application where anyone could directly change an account balance to any number.

That wouldn't be a good design!

Encapsulation means keeping related data and behavior together while controlling how the data can be accessed or modified.

Let's improve our bank account example.

#include <iostream>

class BankAccount {
private:
    double balance = 0.0;

public:
    void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }

    double getBalance() const {
        return balance;
    }
};

int main() {
    BankAccount account;

    account.deposit(500);

    std::cout << account.getBalance() << "\n";

    return 0;
}

Output:

500

The balance is private, so outside code cannot modify it directly.

Instead, the deposit() function checks whether the amount is positive before updating the balance.

This is a simple example of protecting an object's internal state.

In real financial software, monetary values also require careful representation and validation. A basic double is not generally suitable for exact financial accounting.

Remember: Encapsulation helps protect data by providing controlled ways to access and modify it.

6. Constructors

What if we want every new student object to receive a name and age immediately?

We can use a constructor!

A constructor is a special member function used to initialize an object when it is created.

It has the same name as the class and no return type.

#include <iostream>
#include <string>

class Student {
private:
    std::string name;
    int age;

public:
    Student(std::string studentName, int studentAge)
        : name(studentName), age(studentAge) {
    }

    void introduce() const {
        std::cout << name << " is "
                  << age << " years old.\n";
    }
};

int main() {
    Student student("Alex", 18);

    student.introduce();

    return 0;
}

Output:

Alex is 18 years old.

How Does It Work?

When we create the object:

Student student("Alex", 18);

C++ calls the constructor with the provided arguments.

This part:

: name(studentName), age(studentAge)

is called a member initializer list. It initializes the object's members before the constructor body runs.

Default Constructors

A default constructor can be called without arguments.

class Player {
public:
    int health;

    Player() : health(100) {
    }
};

Now creating an object with:

Player player;

initializes its health to 100.

Remember: Constructors help ensure that objects begin with the values they need.

7. Destructors

If constructors prepare objects for use, what happens when objects are no longer needed?

That's where destructors come in.

A destructor is a special member function that runs when an object's lifetime ends.

Its name starts with ~, followed by the class name.

#include <iostream>

class Player {
public:
    Player() {
        std::cout << "Player created!\n";
    }

    ~Player() {
        std::cout << "Player destroyed!\n";
    }
};

int main() {
    Player player;

    return 0;
}

Output:

Player created!
Player destroyed!

The constructor runs when the object is created.

The destructor runs when the local object reaches the end of its lifetime.

Destructors are especially useful for releasing resources such as files or dynamically allocated memory.

For simple classes, C++ usually provides a suitable destructor automatically.

Remember: Constructors initialize objects, while destructors help clean up resources when objects are destroyed.

8. The this Pointer

Sometimes a function parameter has the same name as a class member.

How does C++ know which one we mean?

We can use a special pointer called this.

Inside a non-static member function, this points to the object on which the function was called.

#include <iostream>

class Player {
private:
    int health;

public:
    Player(int health) {
        this->health = health;
    }

    void showHealth() const {
        std::cout << health << "\n";
    }
};

int main() {
    Player player(100);

    player.showHealth();

    return 0;
}

Output:

100

In the constructor:

  • this->health — refers to the object's data member.
  • health — refers to the constructor parameter.

The -> operator accesses a member through a pointer.

You don't need to use this in every member function, but it's helpful when names overlap or when you explicitly need to refer to the current object.

Remember: this provides access to the current object inside a non-static member function.

9. Classes vs Structures

You already learned about struct in the previous lesson.

Here's something interesting: classes and structures are very similar in C++!

Both can contain variables, member functions, constructors, destructors, and other members.

The main language differences involve default access and default inheritance access.

class struct
Members are private by default Members are public by default
Default inheritance is private Default inheritance is public
Often used for encapsulated objects Often used for simple data structures

For example:

struct Point {
    int x;
    int y;
};

The members of Point are public by default.

With a class:

class Point {
    int x;
    int y;
};

The members are private by default.

In practice, developers often use struct for simple data containers and class for objects with controlled access to their internal state.

Remember: Both class and struct support object-oriented programming. Choose based on how you want your type to be used.
