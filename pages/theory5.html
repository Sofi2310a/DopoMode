05 — Basic Practice

1. Let's Start Coding!

Now it's time to practice what you've learned!

In the previous lessons, you explored variables, data types, operators, and conditions. Let's use this knowledge to create simple C++ programs.

Your Goal: Complete 4 programming tasks, starting with basic calculations and finishing with a small interactive application.

Try solving each task on your own before looking for help.

2. Task 01 — Simple Calculator

Difficulty: Easy

Create a program that asks the user for two numbers and performs basic mathematical operations.

Requirements:

  • Use double to store both numbers.
  • Calculate addition, subtraction, multiplication, and division.
  • Display the results using cout.
  • Prevent division by zero.

Example Output:

Enter first number: 10
Enter second number: 5

Addition: 15
Subtraction: 5
Multiplication: 50
Division: 2

Hint: Use the operators +, -, *, and /.

Press RUN (or Ctrl + Enter) to compile and run your code.

3. Task 02 — Age Checker

Difficulty: Easy

Create a program that determines a person's age category.

Requirements:

  • Under 13 → Child
  • 13–17 → Teenager
  • 18–64 → Adult
  • 65 or older → Senior

Use if, else if, and else statements. Assume the user enters a valid age.

Example Output:

Enter your age: 16
Category: Teenager

Hint: Check the age conditions in the correct order.

Press RUN (or Ctrl + Enter) to compile and run your code.

4. Task 03 — Grade Calculator

Difficulty: Medium

Create a program that converts a numerical score into a letter grade.

Requirements:

Score Grade
90–100A
80–89B
70–79C
60–69D
0–59F
  • Ask the user to enter a score.
  • Use if-else if statements.
  • Display the corresponding grade.
  • Handle scores outside the range 0–100.

Example Output:

Enter your score: 85
Your grade: B

Hint: Start by checking whether the score is valid.

5. Task 04 — Smart Calculator

Difficulty: Medium

Create a calculator that lets the user choose an operation.

Requirements:

  • Display a menu with four operations.
  • Use switch to process the user's choice.
  • Ask for two numbers.
  • Display the result.
  • Handle invalid choices and division by zero.

Example Output:

SMART CALCULATOR
1. Addition
2. Subtraction
3. Multiplication
4. Division

Choose an operation: 3
Enter first number: 8
Enter second number: 5
Result: 40

Hint: Use switch, case, break, and default.

6. Practice Summary

By completing these four tasks, you will practice:

  • Working with variables and data types.
  • Performing mathematical calculations.
  • Comparing values using operators.
  • Making decisions with if-else.
  • Selecting operations using switch.
  • Handling simple user input errors.

The code is compiled on a remote server (GCC), so an internet connection is required.
