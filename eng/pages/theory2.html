02 — Data Types

Every program needs to work with information: numbers, text, characters, or simple true-or-false answers.

In this lesson, you'll learn how C++ stores different types of information, how to create variables, and how to use them in your programs.

By the end, you'll be able to store and change values, work with text, and choose the right data type for different tasks.

1. What Are Data Types?

Imagine you're creating a program that stores information about a student.

You might need their name, age, height, and whether they're currently enrolled.

These values are different, so C++ uses data types to describe what kind of information each variable holds.

Here are the most common types:

Data TypeWhat It StoresExample
intWhole numbers25
floatDecimal numbers3.14f
doubleMore precise decimal numbers3.14159
charA single character'A'
boolTrue or falsetrue
std::stringText"Hello"

Each type has its own purpose. Choosing the right one helps your program work with information correctly.

Remember: A data type tells C++ what kind of value you're working with.

2. Variables in C++

A variable is a named place where a program stores a value.

Think of it as a labeled box. The label is the variable's name, and the content is its value.

Let's create one:

int age = 18;

Here's what each part means:

  • int — the data type.
  • age — the variable name.
  • 18 — the stored value.
  • ; — ends the statement.

We can create variables for different kinds of information.

#include <iostream>
#include <string>

int main() {
    int age = 18;
    double height = 1.75;
    std::string name = "Alex";

    std::cout << "Name: " << name << "\n";
    std::cout << "Age: " << age << "\n";
    std::cout << "Height: " << height << "\n";

    return 0;
}

Output:

Name: Alex
Age: 18
Height: 1.75

Changing Variable Values

One of the most useful things about variables is that we can update their values.

int score = 10;
score = 20;
std::cout << score;

Output:

20

The original value 10 was replaced with 20.

Notice that we only write int when declaring the variable, not when changing its value.

3. Integer and Decimal Numbers

C++ provides several numeric types. Let's focus on the three you'll use most often.

int — Whole Numbers

Use int when you need numbers without fractional parts.

int age = 20;
int temperature = -5;
int students = 30;

An int can store positive numbers, negative numbers, and zero.

It's useful for ages, scores, counters, and other whole number values.

float — Decimal Numbers

Use float for numbers that may contain fractional parts.

float price = 19.99f;
float weight = 65.5f;

The f tells C++ that the number is a float literal.

A float typically uses 4 bytes and provides about 6–7 significant decimal digits of precision.

double — More Precise Numbers

A double also stores fractional values but usually provides greater precision than float.

double pi = 3.141592653589793;
double distance = 125.75;

A double typically uses 8 bytes and provides about 15–16 significant decimal digits of precision.

For most general calculations involving fractional values, double is a good default choice.

One important detail: floating-point numbers cannot represent every decimal value exactly, so some calculations may have small rounding differences.

Remember: Use int for whole numbers and double for most calculations involving fractional values.

4. Characters and Strings

Programs don't work with numbers alone. They also need to store letters, names, and messages.

char — A Single Character

The char type stores a single character.

char grade = 'A';
char symbol = '#';
char digit = '5';

Characters use single quotation marks.

Notice that '5' is a character, not the integer 5.

std::string — Text

When you need to store a word or sentence, use std::string.

std::string name = "Alex";
std::string message = "Hello, C++!";

Strings use double quotation marks and require the <string> header.

Let's combine both types in a program.

#include <iostream>
#include <string>

int main() {
    char grade = 'A';
    std::string name = "Alex";

    std::cout << "Name: " << name << "\n";
    std::cout << "Grade: " << grade << "\n";

    return 0;
}

Output:

Name: Alex
Grade: A

Remember: char stores a single character, while std::string stores text of different lengths.

5. Boolean Data Type

Sometimes a program only needs to answer a question with yes or no.

For example: Is the student online? Has the game ended? Is the door open?

C++ uses the bool type for these situations.

A Boolean value can be either true or false.

bool isStudent = true;
bool hasLicense = false;

Let's display a Boolean value.

#include <iostream>

int main() {
    bool isOnline = true;

    std::cout << isOnline << "\n";

    return 0;
}

Output:

1

By default, std::cout displays true as 1 and false as 0.

To display the actual words, use std::boolalpha:

std::cout << std::boolalpha << isOnline << "\n";

Output:

true

Boolean values become especially useful when we start writing programs that make decisions.

Remember: Use bool when information has two possible states: true or false.

6. Constants in C++

Not every value should change.

For example, there are always seven days in a week.

We can protect a value from being changed by using the const keyword.

const int daysInWeek = 7;

Now, if we try to change it:

daysInWeek = 8;

The compiler will report an error.

Constants are useful for values that should remain unchanged throughout a particular part of your program.

They also make code easier to understand and reduce accidental modifications.

Remember: Use const when a value should not be changed after initialization.

7. Naming Variables

Good variable names make programs easier to read.

Compare these two examples:

int x = 18;
int studentAge = 18;

Both are valid, but the second one clearly tells us what the variable represents.

Basic Naming Rules

Variable names in C++:

  • Can contain letters, numbers, and underscores.
  • Cannot begin with a number.
  • Cannot contain spaces.
  • Cannot use reserved keywords such as int or return.
  • Are case sensitive.

Valid examples:

int studentAge = 18;
int total_score = 100;
int number2 = 25;

Invalid examples:

int 2number = 10;
int student age = 18;
int return = 5;

For this course, we'll generally use camelCase, where the first word starts with a lowercase letter and each following word begins with a capital letter.

For example: studentAge, totalScore, favoriteNumber

Remember: Choose names that explain what your variables represent.

8. Type Conversion

Sometimes we need to change a value from one data type to another. This is called type conversion.

There are two common approaches.

Automatic Conversion

C++ can convert certain values automatically.

int number = 10;
double result = number;

std::cout << result;

Output:

10

The integer value was converted to a double. The output still displays 10 because it doesn't automatically show a decimal part.

Explicit Conversion

We can also request a conversion ourselves using static_cast.

double price = 19.99;
int wholePrice = static_cast<int>(price);

std::cout << wholePrice;

Output:

19

The fractional part was removed.

This happens because converting a finite double to int truncates the fractional part toward zero, as long as the resulting integer is within the type's supported range. Be careful: some conversions can lose information.

Remember: Type conversion is useful, but changing data types can affect the value.

9. Lesson Summary

  • Data types describe what kind of value a variable holds.
  • Variables store values and can be updated.
  • Use int for whole numbers and double for most fractional values.
  • char stores one character, std::string stores text.
  • bool stores true or false.
  • const protects a value from changes.
  • Use clear camelCase names and be careful with type conversion.
